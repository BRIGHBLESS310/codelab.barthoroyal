JavaScript Strings

Strings represent text and are immutable. Use template literals with backticks to interpolate values or write multi-line strings.

Understand the topic

Text values are strings

A string is immutable text written with single quotes, double quotes, or backticks. Template literals interpolate expressions and support multiline text. Its length reports UTF-16 code units, not always the number of characters people perceive.

Combine and interpolate text

+ concatenates strings; template literals insert expressions with ${...}. Interpolation evaluates JavaScript, so move complex calculations into named variables. Convert other values intentionally when the distinction matters.

Text operations create new values

Operations that seem to change a string actually return a new string; save the result to keep it. Unicode symbols can occupy multiple code units, so length and indexing may differ from visible characters. String fundamentals support methods, JSON, and form input.

Build and inspect text

String indexes start at zero. Methods such as slice() return part of a string without changing the original.

const learner = "Ada";
const greeting = `Welcome, ${learner}!`;
console.log(greeting);
