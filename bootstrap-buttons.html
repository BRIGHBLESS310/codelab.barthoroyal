Buttons

Explore buttons through a practical example and a focused exercise.

How it works

Button classes give links and buttons a consistent appearance. The element should match the action: links navigate, buttons act.

Build the mental model

Bootstrap button classes provide consistent shape, color, size, and state styling for controls. Use a button for an action and an anchor with a real destination for navigation; matching appearance does not make these behaviors interchangeable.

How to apply it

Button variants communicate priority, while disabled and focus states affect whether and how the control can be used. Ensure the label describes the action, and preserve a visible focus indicator for keyboard navigation.

Common pitfalls

A button inside a form submits by default unless its type is set; choose button, submit, or reset intentionally. Avoid using color alone to distinguish actions.

<a class="btn btn-primary" href="register.html">Register for the workshop</a>
<button class="btn btn-outline-secondary" type="button">Save draft</button>

Try the example with keyboard focus and inside a form, then verify that its visual treatment matches the action it actually performs.

Practice

Create a primary navigation link and secondary action button with appropriate elements.
