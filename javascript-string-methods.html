JavaScript String Methods

String methods inspect or create text without changing the original string. Common methods include trim(), includes(), startsWith(), replace(), and split().

Understand the topic

Methods inspect and produce strings

String methods search, extract, replace, and transform text. includes(), slice(), replace(), and trim() cover common tasks. Strings are immutable, so these operations return a new string instead of changing the original.

Indexes and matching details matter

slice(start, end) excludes the end position, and includes() is case-sensitive. JavaScript string indexes count UTF-16 code units, so a visible character made from several units needs more careful handling.

Save the result when needed

Calling trim() without assigning its result leaves the source unchanged. Distinguish substring search from exact equality, and choose locale-aware behavior for human language text. String methods support regex matching and safe input processing.

Clean and split text

Choose methods based on the input format, and validate data rather than assuming it always matches expectations.

const input = "  JavaScript basics  ";
const clean = input.trim();
console.log(clean.includes("basics"));
console.log(clean.split(" "));
