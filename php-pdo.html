Database Access with PDO

PDO provides a database interface. Prepared statements keep values separate from SQL syntax; do not concatenate submitted input into query strings. Handle errors without exposing credentials or internal details to visitors.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

PDO provides a database interface. Prepared statements keep values separate from SQL syntax; do not concatenate submitted input into query strings. Handle errors without exposing credentials or internal details to visitors.

PDO provides a consistent interface to supported databases. A prepared statement separates SQL structure from parameter values, preventing submitted text from being interpreted as SQL syntax. Bind values through placeholders rather than concatenating them into the query string.

Choose an appropriate error-handling strategy and log diagnostic details on the server, not in the visitor's response. Validate values before database operations and use transactions when multiple changes must succeed or fail together. Parameter placeholders protect values, not table or column names.

Example

<?php
$stmt = $pdo->prepare("SELECT id, name FROM users WHERE email = :email");
$stmt->execute(["email" => $email]);
$user = $stmt->fetch(PDO::FETCH_ASSOC);

Run or adapt this example in an appropriate local learning environment. Pay attention to the inputs, the result, and any assumptions the code makes.

Practice

Use a named parameter in a PDO query and handle the case where no row is found.
