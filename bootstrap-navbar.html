Navigation Bar

Explore navigation bar through a practical example and a focused exercise.

How it works

The navbar creates responsive site navigation. Its collapse behavior requires the Bootstrap JavaScript bundle.

Build the mental model

A navbar provides a consistent place for site navigation and may collapse links when available width is limited. Its semantic navigation landmark needs an accessible label when a page has more than one navigation region.

How to apply it

Bootstrap's responsive toggler updates a target collapse region and should expose its expanded state to assistive technology. The toggle button needs a meaningful accessible name, and the menu's links should remain keyboard reachable.

Common pitfalls

A navbar requires the JavaScript plugin for its collapse interaction; CSS-only styling does not make the toggler operate. Test at the breakpoint where it changes, and ensure the menu is still usable with keyboard and zoom.

<nav class="navbar navbar-expand-lg bg-body-tertiary"><div class="container">
  <a class="navbar-brand" href="index.html">Field Notes</a>
  <button class="navbar-toggler" data-bs-toggle="collapse" data-bs-target="#siteNav" aria-controls="siteNav" aria-expanded="false" aria-label="Toggle navigation">Menu</button>
  <div class="collapse navbar-collapse" id="siteNav"><a class="nav-link" href="about.html">About</a></div>
</div></nav>

Activate the toggler with keyboard and pointer, and compare its expanded state with the visibility of the navigation links.

Practice

Add two links and test the navbar toggle with mouse and keyboard on a narrow viewport.
