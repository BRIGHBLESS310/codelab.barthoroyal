Functions

Explanation

Functions give reusable work a name. Declare parameter and return types, use descriptive names, and keep each function focused. Pass larger read-only inputs by const reference to avoid unnecessary copies.

A function declaration specifies a return type, name, and typed parameters. Calling the function supplies arguments; a return statement sends a result to the caller. Use void when no result is returned and keep one function focused on one responsibility.

Passing a large read-only object by const reference avoids copying while preventing modification through that parameter. Small types such as integers are commonly passed by value. These choices define a function's interface and help classes and callers use it safely.

Example

int square(int value) {
    return value * value;
}

int main() {
    std::cout << square(5) << '\n';
}
