JavaScript Math

The built-in Math object provides constants and functions for common calculations, including rounding, minimum and maximum values, and square roots.

Understand the topic

Built-in numeric operations

The global Math object provides constants and functions for common calculations: rounding, powers, roots, absolute values, minima, and maxima. Call methods such as Math.sqrt(value) directly; Math is not constructed with new.

Rounding rules differ

Math.floor() rounds toward negative infinity, Math.ceil() toward positive infinity, and Math.round() to the nearest integer under JavaScript rules. Floating-point calculations can retain tiny precision differences, so choose a strategy suited to the data.

Random is not secure

Math.random() gives a pseudorandom value from zero inclusive to one exclusive; scaling and flooring can map it to an integer range. Do not use it for security-sensitive tokens; use a cryptographic API instead. Math builds on number fundamentals.

Math helpers

Math.random() returns a pseudo-random number from zero up to but not including one. It is not suitable for security-sensitive randomness.

console.log(Math.round(4.6));
console.log(Math.max(3, 8, 5));
console.log(Math.sqrt(81));

Practice

Use Math.max() to find the largest of three scores and Math.round() to round an average.
