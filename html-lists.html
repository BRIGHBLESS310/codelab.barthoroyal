Lists

Explore lists through a practical example and a focused exercise.

How it works

Use lists when items form a group. Unordered lists suit collections without a sequence; ordered lists suit steps or rankings.

Build the mental model

Use ul for a collection whose order is not meaningful and ol when sequence or ranking matters. Each direct item belongs in an li; a nested list belongs inside the item that introduces that subtopic.

How to apply it

Lists expose grouping and order in the document structure, which is more useful than manually typing bullets or numbers into paragraphs. Browsers supply markers and indentation by default, and CSS can adjust those presentation details without changing the underlying meaning.

Common pitfalls

Avoid using a list merely to create indentation, and do not put unrelated content directly between list items. For a sequence such as instructions, preserve the order in markup so the list remains understandable when styling is absent.

<ul><li>Notebook</li><li>Pencil</li></ul>
<ol><li>Preheat the oven</li><li>Mix ingredients</li></ol>

Change the example from an unordered collection to an ordered sequence only when the order changes the meaning, and check that every item remains inside the list.

Practice

Create a packing list and numbered instructions using the appropriate list types.
