JavaScript Data Types

JavaScript values include strings, numbers, booleans, undefined, null, symbols, big integers, and objects. Arrays and functions are objects too.

Understand the topic

Values have different kinds

A data type describes a value and the operations that make sense for it. JavaScript has primitives including strings, numbers, booleans, undefined, null, bigint, and symbol, plus objects such as arrays and functions. Type awareness helps explain behavior and errors.

Primitives and objects behave differently

Assigning a primitive copies its value; assigning an object copies a reference, so two variables can observe changes to the same object. typeof checks many types but reports "object" for both arrays and null; use Array.isArray() for arrays.

Do not infer too much from a type check

A variable can hold different types over time, but changing its role repeatedly invites bugs. Empty arrays and objects are truthy, and typeof null is a historical quirk. Type awareness connects directly to conversion, comparisons, and choosing safe operations.

Basic values

Use typeof to inspect many values, but note that typeof null is the historical string "object". Choose data types that represent information clearly.

const title = "Intro";
const count = 3;
const finished = false;
const selected = null;
console.log(typeof title, typeof count);
