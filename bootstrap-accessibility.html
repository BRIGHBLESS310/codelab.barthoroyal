Accessibility and Responsive Checks

Explore accessibility and responsive checks through a practical example and a focused exercise.

How it works

Bootstrap provides patterns, but authors remain responsible for semantics, labels, contrast, keyboard use, and responsive behavior.

Build the mental model

Bootstrap includes useful responsive and component patterns, but accessibility depends on the semantics and content supplied by the author. Correct headings, labels, landmarks, names, and status messages are still necessary.

How to apply it

Test interaction through keyboard focus, zoom, and touch-sized controls as well as a visual scan. At narrow widths, confirm that content reflows and that text, forms, and navigation do not require two-dimensional page scrolling.

Common pitfalls

A component looking correct at one desktop width does not prove that it works for assistive technology or keyboard users. Check color contrast, visible focus, labels, dynamic announcements, and reduced-motion behavior for the actual page.

Practice

Audit a page using keyboard navigation, zoom, labels, contrast, and a small viewport; fix and retest.
