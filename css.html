CSS Tutorial

CSS controls how HTML content looks and lays out on screens. Learn reusable rules, layout systems, and responsive design.

Learning goal: Build clear, accessible pages and apply the course concepts in real projects.

Start learning CSS

Follow the vertical course sidebar in order. Each topic has its own lesson with an explanation, a code example, and a focused practice task. Start with CSS Syntax and Rules.

/* styles.css */
body {
  color: #172033;
  line-height: 1.6;
}
.card { padding: 1rem; border-radius: 0.75rem; }

Try the example in a local page or your preferred editor. Change one part at a time and observe what happens.

What you will learn

  • Foundations: Understand the syntax and building blocks used throughout the course.
  • Practical patterns: Apply concepts to realistic pages and interface components.
  • Good habits: Keep your work readable, responsive, and accessible.
  • Practice: Every topic ends with a small task to help you apply what you learned.

How to build durable skills

Understand the model

CSS describes how browser-rendered HTML is presented and arranged. Rules match parts of the document, then the cascade determines which declarations apply; layout, typography, color, and motion are all parts of that presentation layer.

Connect ideas to practice

Start with readable defaults and reusable rules, then choose the layout tool that fits: normal flow for text, Flexbox for a single axis, and Grid for rows and columns. Relative sizing and responsive rules help the same content fit different viewports.

Check your work

When a style does not appear, inspect selector matches, cascade priority, and computed values before adding overrides. Test at multiple widths, zoom levels, and focus states so visual polish does not come at the cost of usability.

Practice: make a small page

Choose a topic from the sidebar and use its practice prompt to add one improvement to a personal project. Keep the page clear and test it at more than one screen size.

Build on HTML and CSS, then explore JavaScript.
