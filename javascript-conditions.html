JavaScript Conditions

Use if, else if, and else to choose code based on a condition. Conditions are evaluated as truthy or falsy values.

Understand the topic

Choose a path from a condition

A conditional runs different code depending on whether an expression is truthy or falsy. if handles a case, else if adds alternatives, and else supplies a fallback. This is how programs respond to state and user choices.

Branches are tested in order

JavaScript evaluates branches top to bottom and executes only the first matching branch. Put specific cases before broad ones and use braces so later edits do not change which statements are controlled. Parentheses help show how combined logical conditions are grouped.

Truthiness is not a precise test

Zero, empty string, NaN, null, and undefined are falsy; empty arrays and objects are truthy. A truthiness check can mistakenly reject a valid zero. Use explicit comparisons when the requirement concerns a particular value or missing state.

Choose a branch

Use clear comparisons rather than relying on truthiness when a value's exact meaning matters.

const score = 82;
if (score >= 90) {
    console.log("Excellent");
} else if (score >= 60) {
    console.log("Passed");
} else {
    console.log("Keep practicing");
}

Practice

Change the score and test the program at the boundaries between each result.
