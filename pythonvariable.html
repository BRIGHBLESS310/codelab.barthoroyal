Python Variables

A variable is a name that refers to a value. In Python, assignment creates or rebinds that name, so you can begin using a variable as soon as you give it a value.

Creating Variables

Python has no command for declaring a variable. A variable is created the moment you first assign a value to it:

The equals sign here is an assignment operator: it binds the name on the left to the result on the right. Names can then be used in later expressions, which makes programs easier to change than repeating literal values throughout the code.

Basic Variables Example 
x = 5
y = "John"
print(x)
print(y)

Python is dynamically typed: values have types, while variable names are not permanently declared with one type. Reassigning a name to a different kind of value is allowed, but doing so unnecessarily can make code harder to understand. Clear names and consistent roles help prevent accidental mix-ups.

Variable Names & Rules

A variable can have a short name (like x and y) or a more descriptive name (age, carname, total_volume).

  • Must start with a letter or the underscore character.
  • Cannot start with a number.
  • Can only contain alpha-numeric characters and underscores (A-z, 0-9, and _ ).
  • Variable names are case-sensitive (age, Age, and AGE are three different variables).

Names are case-sensitive, so age and Age refer to different variables. Prefer descriptive snake_case names for ordinary variables; avoid using Python keywords such as if or class, because they already have a language-defined role.
