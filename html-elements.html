Elements and Attributes

Explore elements and attributes through a practical example and a focused exercise.

How it works

Elements use tags to describe content, while attributes configure an element or provide additional information. Nest tags in the right order.

Build the mental model

An element is the complete construct: usually an opening tag, content, and a closing tag. Tags mark the boundaries, while the browser interprets the element's meaning and default behavior; some elements, such as img and br, are void and have no closing tag.

How to apply it

Attributes are written in an element's start tag as name-value pairs. Global attributes such as id, class, and lang apply widely, while others are element-specific; quote attribute values so spaces and special characters are handled predictably.

Common pitfalls

HTML is forgiving of many syntax mistakes, but browser recovery can hide errors and produce a DOM different from what you intended. Nest elements properly, use lowercase tag names by convention, and choose elements for meaning rather than for their default appearance.
