Create two-dimensional layouts

CSS Grid arranges content in rows and columns. Tailwind utilities can define columns, gaps, alignment, and responsive changes without writing separate selector rules.

Key idea

Grid works well for repeated cards or dashboards where both row and column alignment matter. Use a single column on small screens, then add columns at suitable breakpoints.

Think in tracks and placement

CSS Grid defines tracks—rows and columns—and places children into the resulting two-dimensional space. A declaration such as grid-cols-3 establishes three equal columns; a gap utility adds space between tracks without adding margins to each child.

Grid is a good fit when alignment across both dimensions matters, such as a card gallery or a dashboard. A responsive grid can change its column count at breakpoints, but fixed track counts may overflow when a container is narrow. Consider minimum track sizes and the content's natural width.

Grid controls the container's layout, while the child utilities control each item's own appearance. Keeping those roles separate helps debug unexpected placement: first check the parent’s grid definition, then the item’s span or order. Use Flexbox when the layout is fundamentally a single row or column.

Example

The grid starts with one column and expands at the small and large breakpoints. The gap applies in both directions.

<div class="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3">
  <article class="rounded-lg border p-4">Plan</article>
  <article class="rounded-lg border p-4">Build</article>
  <article class="rounded-lg border p-4">Review</article>
</div>

Practice

Make a card grid that has one column by default and three columns on a wide screen. Add enough sample cards to see how rows fill.
