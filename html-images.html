Images and Alternative Text

Explore images and alternative text through a practical example and a focused exercise.

How it works

The img element embeds an image. Its alt text communicates the image's purpose when it cannot be seen or loaded.

Build the mental model

The src attribute identifies the image resource; the alt text communicates its purpose when the image cannot be seen or loaded. Write alternative text for the context, not as a mechanical inventory of every visible detail.

How to apply it

For an informative image, describe the information it adds to the surrounding content. For a purely decorative image that adds no information, use an empty alt="" so assistive technology can skip it; nearby text may make a repeated description unnecessary.

Common pitfalls

Provide intrinsic width and height when known to reserve layout space, and use responsive CSS to fit the image into its container. Avoid filenames or phrases like “image of” as alt text, and never omit the alt attribute.

<img src="market.jpg" alt="A vendor arranging oranges" width="800" height="500">
<img src="ornament.svg" alt="">

Ask what a reader would miss if the image disappeared, and make the alternative text supply that information without repeating adjacent copy.

Practice

Choose an informative and a decorative image. Write suitable alt values and explain your choices.
