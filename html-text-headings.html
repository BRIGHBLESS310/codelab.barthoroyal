Text and Headings

Explore text and headings through a practical example and a focused exercise.

How it works

Headings organize a page hierarchy and paragraphs represent prose. Use heading levels to reflect nested sections, not to choose a font size.

Build the mental model

Heading elements express the outline of a page: h1 is the top-level heading, followed by nested levels through h6. Paragraphs represent prose, while elements such as strong and em add meaning to a phrase rather than merely changing its visual style.

How to apply it

A logical heading hierarchy helps readers scan and navigate a document, including people using screen-reader heading lists. Choose a level according to the section's place in the outline, not the size you want; CSS can control visual size independently.

Common pitfalls

Do not skip heading levels just to get a smaller default font, and do not use repeated line breaks to create paragraph spacing. Write concise, descriptive headings so both visual readers and assistive-technology users can predict what follows.

<h1>Field Notes</h1>
<p>Observations from recent walks.</p>
<h2>Coastal path</h2>
<p><strong>Best time:</strong> early morning.</p>

Read the heading levels as a nested outline, then use browser developer tools to inspect the structure separately from its visual styling.

Practice

Write a short article with a page heading, two section headings, and paragraphs in a logical order.
