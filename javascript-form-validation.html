JavaScript Form Validation

HTML provides built-in constraints such as required, input types, and length limits. JavaScript can add user-friendly feedback, but client-side checks are not a substitute for server-side validation.

Understand the topic

Validation checks whether input meets rules

Form validation checks submitted values against requirements such as presence, length, format, or range. HTML constraints like required, type="email", and minlength provide built-in checks; JavaScript adds contextual rules.

Give actionable feedback

A submit handler can inspect values, use checkValidity(), and show a message near the relevant field. Explain what needs correction, retain entered values, and consider validation while editing. Users should be able to identify and fix each problem.

Client validation is not a security boundary

Users can bypass browser code, so a server must validate data independently before accepting it. Do not rely only on color to show an error; provide text and accessible state. Validation combines forms and events to help people correct mistakes.

Use browser validity checks

Explain what the user needs to correct and associate error messages with their fields.

const email = document.querySelector("#email");
if (email?.validity.valid) {
    console.log("Email field passes browser validation");
} else {
    email?.reportValidity();
}

Practice

Add required and type=email to a field, then test invalid and valid submissions.
