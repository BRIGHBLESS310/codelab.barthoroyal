C++ Tutorial

C++ is a compiled, general-purpose language used for systems, tools, games, and performance-sensitive applications. Learn modern C++ fundamentals through small programs and standard-library examples.

Learning goal: Write clear, type-safe C++ programs and use standard-library abstractions for values and resources. Follow the course in order or choose a topic in the sidebar. Each lesson has its own page and previous/next links.

Start learning C++

Begin with C++ Get Started. Read the explanation, try the example in a suitable environment, and complete its practice prompt.

  • Get Started: A C++ source file is compiled into a program with a compiler such as GCC, Clang, or MSVC. Use a recent compiler and select a language standard such as C++17 or newer.
  • Program Structure and Output: A program starts at main. Include headers for facilities you use and qualify standard-library names with std::. Statements commonly end in semicolons; indentation makes blocks easier to read.
  • Variables and Types: A variable's type determines its valid values and operations. Initialize values when declaring them and prefer const when a value should not change. Standard types include int, double, bool, and std::string.
  • Input and Expressions: std::cin reads formatted input. Arithmetic follows operator precedence; parentheses can make intent clearer. Check extraction when input may be invalid. std::getline reads a whole line, including spaces.

How to get the most from this course

  1. Work through the chapters in order; each topic links directly to its dedicated lesson file.
  2. Type and adapt examples instead of only reading them.
  3. Try the practice prompt, then use previous and next links to review or continue.
  4. Use a local development or practice environment for experiments.
