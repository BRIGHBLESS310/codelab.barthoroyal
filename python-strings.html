Python Strings

A string (str) is an immutable sequence of text characters. Write it with matching single or double quotes; triple quotes can preserve line breaks in multi-line text.

Work with text

name = "Ada"
greeting = f"Hello, {name}!"
print(greeting)
print(name.upper())
print("red,blue".split(","))

Strings are immutable: methods return new strings instead of changing the original value. Use f-strings to insert values into text.

Immutability means an operation such as name.upper() gives you a new string and leaves name unchanged. If you need the transformed text later, assign the result to a variable. F-strings evaluate expressions inside braces when the string is created, which is convenient for readable messages.

Useful operations

  • Index and slice: Get a character with text[0] or a portion with text[1:4].
  • Length: Use len(text) to count characters.
  • Search: Use in to check whether a substring appears.
  • Methods: Explore strip(), replace(), split(), and join().
  • Formatting: Prefer f-strings for readable interpolation.

String indexes start at zero, and negative indexes count from the end. A slice such as text[start:stop] includes the start position but excludes the stop position, so its length is often stop - start. This convention makes adjacent slices easy to join without overlap.

Methods such as strip() and split() are useful when cleaning input, but they do not mutate the source string. For example, remove surrounding spaces before checking a name, and use "-".join(parts) to combine a sequence of strings; the separator is the string that calls join().

Practice

Ask for a person's name and print a friendly greeting using an f-string. Try trimming extra spaces with strip() first.
