Updating Arrays and Objects

Update state immutably: spread objects to change properties and create new arrays when adding, removing, or updating items. Compute derived values from state rather than keeping duplicate copies.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

React treats state as a render snapshot. Do not mutate an object or array stored in state; create a new value with spread, map, or filter so React can detect the update and old references stay unchanged.

Use a functional setter when an update depends on prior state. Spread preserves array entries, map replaces a matching entry, and filter removes entries; each operation returns a new array without editing the original.

Nested data requires copying every changed level. For deeply nested objects, choose a simpler state shape or a well-established immutable-update helper instead of mutating a nested value in place.

The example appends through the updater form, which remains correct if updates are queued. For todos, identify entries by stable IDs when removing or editing rather than relying on current positions.

Example

const [items, setItems] = useState(["Read"]);

function addItem() {
  setItems(current => [...current, "Practice"]);
}

function renameFirst() {
  setItems(current => current.map((item, index) =>
    index === 0 ? "Review" : item
  ));
}

Practice

Create a todo list that adds and removes items without mutating its state array.
