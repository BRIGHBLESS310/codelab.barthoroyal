Java Loops

Loops repeat a block of code. Pick the loop that makes the stopping condition and number of repetitions easy to understand.

While loop

A while loop checks its condition before each iteration. Update the values used by the condition so that it eventually becomes false.

int count = 3;
while (count > 0) {
    System.out.println(count);
    count--;
}
System.out.println("Go!");

If the condition never becomes false, the loop will continue indefinitely. This is called an infinite loop.

Think of a while loop as “repeat while this condition is true.” The condition is checked before the body, so it may execute zero times; this is useful when the number of repetitions depends on input or some changing state.

To reason about termination, identify which value affects the condition and how the body changes it. Missing an update, or updating in the wrong direction, is a common reason a loop never stops.

For loop

A traditional for loop puts initialization, continuation condition, and update in one place. It is often useful when counting iterations.

for (int number = 1; number <= 5; number++) {
    System.out.println(number);
}

The three parts are initialization (int number = 1), continuation test (number <= 5), and update (number++). After each iteration, the update runs and then the condition is checked again; when it becomes false, execution continues after the loop.

Pay attention to inclusive and exclusive bounds. A loop with < 5 runs for values 1 through 4, while <= 5 includes 5. Consistent bounds become especially important when indexing arrays.

Enhanced for loop

Use the enhanced for loop to visit every element of an array or collection when you do not need to change the index.

String[] names = {"Ada", "Lin", "Sam"};
for (String name : names) {
    System.out.println(name);
}

Each iteration assigns the next element to the loop variable, so the loop naturally reads every value without manually managing an index. This makes the enhanced form less error-prone when position is not relevant.

The loop variable is a local variable for the loop body. Reassigning it does not replace the corresponding element in the array; use an indexed loop when you need to update elements by position.

Break and continue

break exits the nearest loop. continue skips the rest of the current iteration and proceeds to the next one.

for (int number = 1; number <= 6; number++) {
    if (number == 2) {
        continue;
    }
    if (number == 5) {
        break;
    }
    System.out.println(number);
}

Use these statements sparingly; a clear loop condition is usually easier to follow.

break ends only the nearest enclosing loop, and continue skips to that loop's next iteration. In nested loops, be sure you understand which loop a jump affects; extracting a task into a method can sometimes make early exits clearer.

Before adding a jump, check whether you can express the same behavior in the loop condition or with a well-named helper. Straight-line flow makes it easier to verify that every value is processed exactly once.

Print the multiples of 3 from 3 to 30. Then change the loop to calculate their total instead of printing each value.
