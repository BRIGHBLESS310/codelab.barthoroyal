JavaScript Functions

Functions package reusable behavior. A function can accept parameters and return a value. Arrow functions are concise and are commonly used for callbacks.

Understand the topic

Reusable behavior with inputs and outputs

A function packages statements into a named unit of behavior. Parameters receive inputs, and return sends a result to the caller. Functions divide a problem into reusable, testable pieces and avoid repeating logic.

Calls create local execution contexts

Parameters and local variables are available during a call. A function without explicit return produces undefined. Function declarations are hoisted; function expressions and arrow functions are initialized according to their variable declarations.

Returning differs from logging

Logging displays a value for a developer; returning makes it available to the rest of the program. A common mistake is omitting return. Arrow functions are concise callbacks, but their this behavior differs from regular functions.

Define and call functions

Functions should have clear responsibilities and names. A function without an explicit return value returns undefined.

function add(left, right) {
    return left + right;
}

const double = value => value * 2;
console.log(add(2, 3), double(4));
