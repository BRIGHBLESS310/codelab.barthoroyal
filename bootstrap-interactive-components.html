Interactive Components

Explore interactive components through a practical example and a focused exercise.

How it works

Bootstrap JavaScript plugins enable modals, dropdowns, and collapsible content. Their triggers connect to targets with data attributes.

Build the mental model

Bootstrap's interactive components use JavaScript plugins to manage behavior such as modal visibility, dropdown state, and collapsible panels. Their data attributes connect controls to targets, while the plugin coordinates state and events.

How to apply it

Interactive patterns need correct semantics and state communication: buttons should expose what they control, expanded or pressed state should be accurate, and focus should move appropriately into and out of a modal.

Common pitfalls

A visual state change alone is not enough for accessibility, and a modal must not trap a person outside the dialog or leave focus lost after closing. Load the matching bundle and test all controls by keyboard.

<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#infoModal">View details</button>
<div class="modal fade" id="infoModal" tabindex="-1" aria-labelledby="infoTitle" aria-hidden="true">
 <div class="modal-dialog"><div class="modal-content"><div class="modal-header">
  <h2 class="modal-title fs-5" id="infoTitle">Details</h2>
  <button class="btn-close" data-bs-dismiss="modal" aria-label="Close"></button>
 </div><div class="modal-body">More information.</div></div></div>
</div>

For each trigger in the example, find its target and state attribute, then open and close it using only the keyboard.

Practice

Add a details modal and test opening, closing, and keyboard focus. Include a clear title and close control.
