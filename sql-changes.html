INSERT, UPDATE, DELETE

INSERT adds rows, UPDATE changes matching rows, and DELETE removes them. Before changing data, inspect the target with SELECT and ensure UPDATE or DELETE has a specific WHERE clause. Practice on a disposable copy.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

INSERT creates rows; explicitly naming the target columns documents the values and avoids relying on column order. Defaults may fill omitted optional columns, while NOT NULL and other constraints can reject incomplete records.

UPDATE changes every row matching WHERE, not just the first row. Before executing one, run a SELECT with the same condition and check the affected-row count. Omitting WHERE can update the entire table; an unqualified DELETE can remove every row.

Use placeholders and bound parameters for values from a form or other external source. Parameters keep data separate from SQL syntax; identifiers such as table names usually cannot be parameterized and need an allow-list if selected dynamically.

The example inserts a named customer, then changes the city for customer_id 7. It intentionally targets a specific identifier. Practice on test data, and use a transaction when partial completion would leave inconsistent data.

Example

INSERT INTO customers (name, city)
VALUES ('Ada', 'Lagos');

UPDATE customers
SET city = 'Abuja'
WHERE customer_id = 7;

Practice

Add a sample row and verify it with SELECT. Practice an update only on test data and confirm its WHERE clause matches the intended row.
