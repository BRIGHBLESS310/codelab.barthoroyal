JavaScript Switch

A switch compares one expression with several cases. Use break to exit a matching case unless intentionally sharing behavior; default handles unmatched values.

Understand the topic

Select among discrete cases

A switch compares one expression with a list of case values and begins at the matching case. It can clarify a set of alternatives compared with a long chain of branches.

Matching is strict and fall-through is possible

Cases use strict equality, so a number and numeric-looking string differ. A break usually ends the selected case; without it execution continues into the next case. Group case labels when they share behavior.

Plan for unexpected values

A default case handles values not listed. Switch is less suitable for ranges or complex predicates, where ordered if statements communicate intent better. Explicit conversion makes the compared value predictable.

Match a case

Cases use strict comparison. Group cases when they should run the same code, and include a default when unexpected values need handling.

const day = "Saturday";
switch (day) {
    case "Saturday":
    case "Sunday":
        console.log("Weekend");
        break;
    default:
        console.log("Weekday");
}
