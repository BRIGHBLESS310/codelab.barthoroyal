JSX and Rendering

JSX is a markup-like syntax transformed by the project toolchain. Put JavaScript expressions inside braces, use attributes such as className, and return a single parent or fragment.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

JSX lets a component describe elements with familiar HTML-like syntax. Build tools transform it into JavaScript; browsers do not execute JSX directly, which is why the project setup matters.

Curly braces insert JavaScript expressions. JSX attributes follow JavaScript conventions: className replaces HTML class, and event handlers such as onClick receive function values rather than strings of code.

A component returns one enclosing element, but a fragment groups siblings without adding a DOM node. Keep expressions focused; move multi-step logic into the component body or a helper to retain readable markup.

The example inserts a variable in a heading and returns a paragraph beside it in a fragment. React escapes text values by default; avoid dangerouslySetInnerHTML unless markup is trusted and safely sanitized.

Example

function Greeting() {
  const name = "CodeLab";
  return <><h1>Hello, {name}!</h1><p>Welcome.</p></>;
}

Practice

Render a profile card using a variable for the person's name and a fragment for multiple elements.
