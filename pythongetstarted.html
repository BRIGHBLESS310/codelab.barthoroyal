Python Get Started

To run Python programs locally, install a Python interpreter and use a terminal or code editor. The browser example on this page is a small preview for introductory snippets, not a complete Python interpreter.

Check if Python is Installed

Many PCs and Macs already have Python installed. To check if you have Python installed on Windows, search in your command line or terminal:

A terminal is a text-based way to ask your operating system to run commands. The version check confirms whether a Python command is available and which version responds; it does not create a project or run a script.

Command Line 
C:\Users\Your Name>python --version

If you see Python installed, it will return the version number (e.g., Python 3.11.x). If you don't have Python installed, you can download it for free from python.org.

After installation, save code in a plain-text file ending in .py and run it with a command such as python filename.py from that file's folder. If python is not recognized, check the installation and PATH settings; on some systems the command is python3.
