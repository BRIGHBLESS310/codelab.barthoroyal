Explanation

A program starts at main. Include headers for facilities you use and qualify standard-library names with std::. Statements commonly end in semicolons; indentation makes blocks easier to read.

The preprocessor handles directives such as #include before compilation. Headers declare standard-library facilities, while main is the program entry point; execution begins there and returns an exit status to the environment.

Keep statements inside braces and terminate declarations and expressions with semicolons. Qualifying names with std:: makes their library origin clear. A program's structure provides the foundation for adding variables, functions, and classes without putting everything into main.

Example

#include <iostream>

int main() {
    const int answer = 42;
    std::cout << "Answer: " << answer << '\n';
    return 0;
}
