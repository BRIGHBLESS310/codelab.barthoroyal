Backgrounds and Borders

Explore backgrounds and borders through a practical example and a focused exercise.

How it works

Background colors and images distinguish regions, while borders define edges and emphasis. Maintain strong text contrast.

Build the mental model

Background properties paint behind an element's content and padding; they can set a color, image, position, size, and repeat behavior. A background image is decorative and does not provide alternative text to assistive technology.

How to apply it

Borders define an element's edge, while radius can soften corners; these properties can communicate grouping or state when used consistently. When an image is meaningful content, use an HTML image with appropriate alternative text instead of hiding it in CSS.

Common pitfalls

Text over a background image needs reliable contrast across every crop and viewport, so a color overlay or solid fallback may be necessary. Avoid oversized assets and remember that a background does not change the element's semantic meaning.

.feature {
  background-color: #e0f2fe;
  background-image: linear-gradient(120deg, #e0f2fe, #f8fafc);
  border: 1px solid #bae6fd;
  border-radius: 1rem;
}

Resize the example and observe how the background is positioned and cropped, then verify that any text remains readable over the entire image.

Practice

Design a callout using a subtle background, border, and rounded corners. Check contrast.
