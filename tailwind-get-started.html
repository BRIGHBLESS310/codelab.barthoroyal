Set up Tailwind CSS

Tailwind scans your project files for class names and generates the CSS your page uses. Setup differs by framework and Tailwind version, so follow the installation guide for the version selected by your project.

Key idea

A typical workflow has three parts: install the version-specific package, connect Tailwind to your build tool, and include the generated stylesheet in the app entry point. In current projects, the setup command and configuration format may differ from older v3 tutorials.

What happens during setup

Tailwind is a build-time CSS generator, not a browser runtime that styles every class it sees. Its scanner examines configured source files, recognizes utility candidates, and emits the CSS rules needed by those candidates. This is why a class in a file the build does not scan can appear in the markup but have no visible effect.

The installation guide must match both the Tailwind major version and the project's bundler. Version 3 commonly uses a configuration file and directives such as @tailwind; version 4 uses a CSS-first setup and different integration packages. Copying instructions across versions can leave the scanner or stylesheet disconnected.

After setup, verify the whole path: the source file is included, the CSS entry point is imported, and the development build refreshes after a class change. The browser's computed styles help distinguish a missing generated rule from a selector conflict or an incorrect utility name.

Example

Keep the build tool responsible for generating CSS; a class name in HTML does not create styles until Tailwind has scanned the file and emitted the matching rule.

/* app.css: the exact directive depends on your Tailwind version */
@import "tailwindcss";

/* In your application entry point, import app.css. */
/* Then write utilities in markup: */
<div class="p-6 text-lg font-semibold">Ready to style</div>

Practice

Create a small page, connect its stylesheet through the project build, and confirm that changing a utility changes the rendered page. Record the Tailwind version and use its matching setup instructions.
