JavaScript Destructuring

Destructuring assigns values from arrays or properties from objects to variables. It can make it clear which values a function uses.

Understand the topic

Unpack values into named variables

Destructuring extracts array positions or object properties into variables. Array patterns follow position, while object patterns use property names. It is useful for focused data access, especially when a function receives an options object or returns related fields.

Patterns can rename and default

Object destructuring can rename a property and provide a default for an undefined value. Array patterns can skip positions or collect the rest. The source must have the expected shape, so destructuring does not remove the need to understand incoming data.

Defaults do not replace null values

A default applies when the matched value is undefined, not null. Destructuring a missing nested object can throw; guard optional data or use optional chaining where suitable. Patterns pair naturally with parameters, spread/rest, and structured API data.

Unpack values

Destructuring supports defaults for missing values and can also be used in function parameters.

const point = [4, 7];
const [x, y] = point;

const learner = { name: "Ada", level: 2 };
const { name, level } = learner;
