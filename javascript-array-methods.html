JavaScript Array Methods

Array methods express common collection operations. map() transforms items, filter() selects items, and find() returns the first matching item.

Understand the topic

Choose the operation by its result

Array methods describe a desired operation on an ordered collection. map() returns a same-length array of transformed values, filter() keeps matching values, and find() returns the first matching value or undefined. Their return values communicate intent.

Callbacks shape each pass

Each method invokes a callback with an element, its index, and the original array. The callback?s return value is important for map() and filter(); chained operations run left to right, each receiving the previous result. Use forEach() when you need an action but no new array.

Avoid mutation surprises

A common mistake is choosing map() for side effects, or assuming every array method leaves the original alone. Methods such as sort() and splice() mutate; map() and filter() do not. This distinction helps keep data transformations predictable.

Transform and select

Use forEach() for an action on each item when you do not need a new array.

const scores = [45, 80, 92];
const passed = scores.filter(score => score >= 60);
const labels = passed.map(score => "Score: " + score);
console.log(labels);
