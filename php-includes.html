Includes and Organization

Include reusable files for shared functions or templates. require is appropriate when a missing file should stop the request. Use __DIR__ for paths relative to the current file, and keep secrets out of public source control.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

Include reusable files for shared functions or templates. require is appropriate when a missing file should stop the request. Use __DIR__ for paths relative to the current file, and keep secrets out of public source control.

Start with the example below, then change one value or condition and observe how the result changes. Check the documentation for your language or database version when details vary.

Example

<?php
require_once __DIR__ . "/helpers.php";

function pageTitle(string $title): void
{
    echo "<h1>" . htmlspecialchars($title, ENT_QUOTES, "UTF-8") . "</h1>";
}

Run or adapt this example in an appropriate local learning environment. Pay attention to the inputs, the result, and any assumptions the code makes.

Practice

Move a reusable helper to a separate file and include it using a path based on __DIR__.
