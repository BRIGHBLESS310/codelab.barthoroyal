JavaScript Async and Await

Mark a function async to make it return a promise. Inside it, await pauses that function until a promise settles, without blocking the browser's main thread.

Understand the topic

A readable way to work with promises

async/await lets asynchronous operations be written in a sequence-like style. An async function always returns a promise; await pauses that function until a promise settles, then produces its value or throws its rejection reason.

Handle success and failure

Use try/catch around operations that can reject when the function can recover or give useful feedback. Await pauses only the current async function, not the browser or other JavaScript tasks. Callers can await or chain the promise returned by the async function.

Do not serialize independent work

Awaiting requests one at a time makes sense when each depends on the prior result, but slows independent tasks. Start independent work together with Promise.all() and choose an error strategy deliberately. Async/await is built on promises, so understanding promise states remains valuable.

Wait for asynchronous work

Handle errors around awaited operations when your code can provide a useful recovery path.

async function loadMessage() {
    try {
        const message = await Promise.resolve("Loaded");
        console.log(message);
    } catch (error) {
        console.error("Could not load the message.", error);
    }
}
