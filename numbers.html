Python Numbers

Python's main numeric types are int for whole numbers, float for approximate decimal values, and complex for numbers with real and imaginary parts. Assign a numeric literal to a name to start using it in calculations.

Python Number Types

Let's look at how each numeric type behaves in Python:

Use integers for counts and indexes, floats for measurements where fractional values matter, and complex numbers for calculations that require an imaginary component. Choosing a type that matches the domain makes later operations clearer and avoids unnecessary conversions.

Integer (int)

Whole Numbers

An int is a whole number, positive or negative, without decimals, of unlimited length.

x = 1
y = 356562225548809
Floating Point (float)

Decimals

A float can be a number, positive or negative, containing one or more decimals.

x = 1.10
y = -35.59
Complex Numbers

Imaginary

Complex numbers are written with a "j" as the imaginary part.

x = 3 + 5j
y = -5j

A float is stored with finite binary precision, so some decimal fractions cannot be represented exactly. This is normal for floating-point arithmetic; for currency or exact decimal rules, consider Python's decimal module in a full Python environment rather than assuming every float is exact.

Type Conversion

You can convert from one type to another with the int(), float(), and complex() methods:

Conversion creates a value of the requested type when the input is valid. Converting a float with int() truncates toward zero rather than rounding, so int(2.8) is 2. Converting text that is not numeric raises an error in Python, so validate external input before using it.

Conversion Example 
x = 1    # int
y = 2.8  # float
z = 1j   # complex

#convert from int to float:
a = float(x)

#convert from float to int:
b = int(y)

#convert from int to complex:
c = complex(x)

print(a)
print(b)
print(c)
