Selectors

Explore selectors through a practical example and a focused exercise.

How it works

Selectors identify which elements receive declarations. Simple selectors include element names, classes, and IDs.

Build the mental model

Selectors match elements in the document tree. Type selectors target element names, class selectors target reusable class tokens, ID selectors target a specific identifier, and attribute selectors can match elements based on their attributes.

How to apply it

Combinators express relationships such as descendants or direct children, letting a rule be scoped to a part of the page. Selector choice affects both where the style applies and how difficult it is for a later rule to override it.

Common pitfalls

Use classes for reusable styling and keep IDs unique; very long, deeply nested selectors couple CSS to a fragile HTML structure. A selector that matches too broadly can create accidental side effects elsewhere in the page.

h1 { color: #075985; }
.card { padding: 1rem; }
.card a { text-decoration: underline; }
#site-header { border-bottom: 1px solid #cbd5e1; }

For each selector, predict which nodes match before opening developer tools, then inspect the matched elements to confirm your reading.
