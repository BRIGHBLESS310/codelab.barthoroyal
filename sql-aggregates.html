Functions and Aggregates

COUNT, SUM, AVG, MIN, and MAX summarize rows. GROUP BY creates one summary per group. WHERE filters input rows before grouping; HAVING filters the groups after aggregation.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

Aggregate functions summarize rows: COUNT counts rows or non-NULL values, SUM adds values, AVG computes a mean, and MIN or MAX finds an extreme. COUNT(*) counts every row; COUNT(column) skips NULLs in that column.

GROUP BY partitions rows that share listed values, then calculates an aggregate for each group. Selected expressions should either be grouped or aggregated; engines differ in how strictly they enforce this rule.

WHERE filters individual rows before groups form; HAVING filters completed groups. An aggregate condition belongs in HAVING, while a condition on an input row usually belongs in WHERE for clarity and efficiency.

The query counts customers per city, keeps cities with at least two records, then sorts by count. Alias use in GROUP BY or HAVING varies by database, so repeating the aggregate expression may be more portable.

Example

SELECT city, COUNT(*) AS customer_count
FROM customers
GROUP BY city
HAVING COUNT(*) >= 2
ORDER BY customer_count DESC;

Practice

Count records per category and use HAVING to show groups above a threshold.
