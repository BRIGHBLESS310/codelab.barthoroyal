JavaScript DOM Selectors

querySelector() returns the first matching element, while querySelectorAll() returns a collection of all matches. Both use CSS selector syntax.

Understand the topic

Find the element you intend to change

DOM selectors locate nodes so JavaScript can read or update a page. querySelector() returns the first match for a CSS selector; querySelectorAll() returns a static NodeList of all matches. IDs, classes, attributes, and element names target page content.

Scope and timing matter

Calling a selector on a container searches only its subtree. A query made before the markup exists may return null; defer the script or wait until the document is ready. Check a single-element result before using its properties.

Selectors must match the document

A misspelled class or invalid selector can yield no match. When many elements match, iterate over the NodeList rather than treating it as one element. Reliable selectors connect DOM structure to events and rendering while keeping code resilient to page changes.

Select page elements

Check that an element exists before using it when the script may run on pages without that element.

const card = document.querySelector(".card");
const buttons = document.querySelectorAll("button");
buttons.forEach(button => {
    button.disabled = false;
});

Practice

Select all links in a page and count them with querySelectorAll().
