Strings and Vectors

std::string represents text and std::vector stores a variable number of values. These standard-library types manage their own memory and are good defaults for ordinary collections.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

std::string represents text and std::vector stores a variable number of values. These standard-library types manage their own memory and are good defaults for ordinary collections.

Start with the example below, then change one value or condition and observe how the result changes. Check the documentation for your language or database version when details vary.

Example

#include <string>
#include <vector>

std::vector<std::string> topics{"Types", "Loops"};
topics.push_back("Functions");
for (const std::string& topic : topics) {
    std::cout << topic << '\n';
}
