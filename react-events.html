Events

Pass a function to an event prop such as onClick. React calls the handler when the user interacts; pass a function reference instead of invoking it during rendering.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

React event props use camelCase names such as onClick and receive a function. Passing handleSave gives React a function to call later; writing handleSave() in JSX would call it during rendering.

An event handler is an appropriate place for an interaction's response: update state, validate an action, or call an application function. Keep rendering pure so React can render again when inputs change.

Native buttons already support keyboard activation and focus, so prefer a real button over a clickable div. Give controls an accessible name and use the correct type inside forms.

The example logs only when the user activates Save. A real interface might show progress and confirmation instead; decide what happens if the operation fails or is activated repeatedly.

Example

function SaveButton() {
  function handleSave() { console.log("Saved"); }
  return <button onClick={handleSave}>Save</button>;
}
