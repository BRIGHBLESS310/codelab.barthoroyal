Transitions and Motion

Explore transitions and motion through a practical example and a focused exercise.

How it works

Transitions animate property changes between states. Motion should be subtle and respect users who prefer reduced motion.

Build the mental model

A transition interpolates a property's value when it changes between states; it does not create a state change by itself. The property, duration, timing function, and optional delay determine which changes animate and how they feel.

How to apply it

Keep motion short and restrained so it clarifies feedback instead of delaying interaction. Limit transitions to properties that can animate smoothly, and use hover or focus styles as the state change that triggers the transition.

Common pitfalls

Long or constant motion can distract or cause discomfort. Respect the user's reduced-motion preference with a media query, avoid animating layout-heavy properties when a transform or color would communicate the change, and keep the interface usable with motion removed.

.button { transition: background-color 160ms ease, transform 160ms ease; }
.button:hover { transform: translateY(-2px); }
@media (prefers-reduced-motion: reduce) { .button { transition: none; } }

Focus the example control using the keyboard as well as hovering, then enable reduced motion in the operating system and check that the interaction remains clear.

Practice

Add a subtle button transition and test the reduced-motion preference.
