JavaScript Arrays

Arrays store ordered collections. Their indexes start at zero, and their length changes as items are added or removed.

Understand the topic

An ordered collection

An array stores multiple values in an ordered collection. Positions are identified by numeric indexes starting at zero, making the final index length - 1. Arrays can contain different kinds of values, though a consistent shape often makes application code easier to understand.

Read, update, and grow the collection

Bracket notation reads or replaces a position, and length reports the number of elements. push() and pop() add or remove at the end; unshift() and shift() operate at the beginning. Use for...of to process each value.

Indexes are not one-based

Index length is one past the final element, so an out-of-range read returns undefined. const prevents reassignment of an array variable but does not freeze its contents. These rules underpin the array methods used to search, transform, and filter data.

Store and access values

Use const when the array binding should not be reassigned; the array's contents can still change.

const lessons = ["Syntax", "Functions"];
lessons.push("Arrays");
console.log(lessons[0]);
console.log(lessons.length);
