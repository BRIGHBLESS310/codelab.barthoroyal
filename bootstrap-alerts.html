Alerts and Feedback

Explore alerts and feedback through a practical example and a focused exercise.

How it works

Alerts communicate status or feedback. Explain what happened; do not convey status through color alone.

Build the mental model

An alert groups a message that reports a condition or result; Bootstrap contextual classes give common statuses a shared visual treatment. The message should state what happened and, where useful, what the person can do next.

How to apply it

A visual alert is not automatically announced to assistive technology when it appears dynamically. Use an appropriate live-region role when feedback must be announced, choosing assertive announcements sparingly so they do not interrupt unrelated work.

Common pitfalls

Do not rely only on a red or green background to identify an error or success, and do not dismiss important information before it can be read. An alert that is merely decorative should not masquerade as urgent feedback.

<div class="alert alert-success" role="status">Your changes have been saved.</div>
<div class="alert alert-warning" role="alert">Check the highlighted fields.</div>

Read the message without looking at its color and determine whether a user can identify the status and the next step from the text alone.

Practice

Add success and warning messages to a form page. Ensure their meaning is clear without color.
