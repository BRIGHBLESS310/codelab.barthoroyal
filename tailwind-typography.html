Build a readable type hierarchy

Typography utilities control font family, size, weight, line height, and letter spacing. A small, consistent hierarchy helps readers tell headings, body copy, labels, and supporting text apart.

Key idea

Use body text that remains comfortable at narrow widths, and give paragraphs enough line height. Avoid relying on color or font size alone to communicate meaning.

Hierarchy should support reading

Typography utilities control font family, size, weight, line height, letter spacing, and text color. Together, these properties establish hierarchy: a heading should be distinct from body copy, while body text should remain comfortable to scan across the available line length.

Size alone does not create good hierarchy. Tight line height can make multi-line headings collide, and very wide paragraphs slow reading. Combine a sensible text size with readable leading and a restrained maximum width; adjust these choices at breakpoints only when the content benefits.

Visual styling and document semantics are related but not interchangeable. Use real heading elements in a logical order rather than styling a generic element to look like a heading. That preserves navigation for assistive technology while the utilities shape its appearance.

Example

The label, heading, and paragraph have distinct roles. Leading and width improve the reading experience beyond choosing a font size.

<article class="max-w-prose text-slate-700">
  <p class="text-sm font-semibold uppercase tracking-wide text-indigo-700">Lesson 01</p>
  <h1 class="mt-2 text-3xl font-bold leading-tight text-slate-950">Design for clarity</h1>
  <p class="mt-4 text-base leading-7">A clear type scale makes a page easier to understand.</p>
</article>

Practice

Create a card with an eyebrow label, a heading, body copy, and a caption. Use a consistent hierarchy and check readability on a phone-sized viewport.

Try the example, change one detail, and explain how the result changes.
