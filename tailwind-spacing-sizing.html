Control spacing and dimensions

Padding adds room inside an element, margin separates it from neighbors, and gap spaces items in a layout. Width and max-width utilities help content remain readable across screen sizes.

Key idea

Use spacing consistently rather than adjusting each element by arbitrary amounts. A max-width on long-form content prevents lines from becoming difficult to scan.

Spacing utilities use a shared scale

Padding creates space inside an element; margin creates space outside it. Tailwind's spacing scale gives these utilities related increments, so repeated gaps and dimensions can align across a page. Directional forms such as px-* affect the horizontal sides, while gap-* spaces items in a layout container.

Prefer layout gaps for spacing between flex or grid children when possible. This keeps the relationship on the parent and avoids unexpected margin collapse or inconsistent edge spacing. Use max-w-* to limit readable content width and responsive sizing where the design should adapt to its container.

More space is not automatically better: oversized padding can crowd small screens, while fixed widths can cause overflow or truncation. Test with realistic content and narrow viewports. When a scale value is nearly right, first check whether a neighboring token better preserves consistency before choosing an arbitrary value.

Example

The section is centered and capped in width; padding protects its edge, while space-y separates its direct children. The paragraph has an even narrower reading measure.

<section class="mx-auto max-w-2xl space-y-4 p-6">
  <h2 class="text-2xl font-bold">Course notes</h2>
  <p class="max-w-prose">A readable measure makes longer explanations easier to follow.</p>
</section>
