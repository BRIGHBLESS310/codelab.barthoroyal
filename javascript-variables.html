JavaScript Variables

Variables give names to values. Use const when a binding will not be reassigned and let when it will. Avoid var in new code because its function-scoped behavior can be surprising.

Understand the topic

Names make values reusable

A variable is a named binding that lets code refer to a value. Descriptive names make calculations and decisions understandable; reassignment changes what a mutable binding refers to. Variables can hold primitives, objects, functions, and expression results.

Declaration, initialization, reassignment

A declaration introduces a name; initialization gives it a value; reassignment changes it later. let permits reassignment and const prevents it. Older var is function-scoped and can behave unexpectedly around blocks.

Choose a stable meaning and narrow scope

Reusing a variable for unrelated meanings makes debugging harder. Prefer const unless reassignment is needed and declare values close to their use. A constant object reference does not make the object immutable; these choices connect to scope and data types.

Declare and update values

Choose descriptive names that explain a value's purpose. A const object can still have its properties changed; const prevents reassignment of the variable itself.

const course = "JavaScript";
let lessonCount = 1;
lessonCount += 1;
console.log(course, lessonCount);
