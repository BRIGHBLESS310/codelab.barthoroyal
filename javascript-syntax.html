JavaScript Syntax

JavaScript is case-sensitive. Braces group blocks, and statements can end with semicolons. Consistent indentation makes nested code easier to follow.

Understand the topic

Syntax is JavaScript grammar

Syntax defines valid arrangements of keywords, identifiers, literals, operators, and delimiters. The browser parses this grammar before execution, so syntax errors prevent the affected script from running.

Punctuation carries meaning

Braces group blocks and object literals; parentheses group expressions and function parameters; brackets access indexes or computed properties. JavaScript is case-sensitive, so total and Total differ. Indentation helps expose structure even when it does not change semantics.

Separate parse errors from wrong results

A missing delimiter often causes a parse error; a valid expression with the wrong operator is a logic error. Read the console message and inspect nearby code because the mistake may precede the reported location. Syntax supports every later topic.

Statements and blocks

Strings can use single quotes, double quotes, or template literals. Use parentheses to make complex expressions easier to read.

const message = "Hello!";
if (message.length > 0) {
    console.log(message);
}
