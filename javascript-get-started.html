JavaScript Get Started

JavaScript runs in web browsers and server-side environments such as Node.js. Try code in a browser console or load a script from an HTML page.

Understand the topic

JavaScript runs in different environments

JavaScript adds behavior to browser pages and also runs in environments such as Node.js. In a browser it can inspect the DOM, respond to events, and request data. The language?s core is shared, though host APIs differ.

Connect a script to an HTML page

A script can be inline or loaded from a separate .js file with src. External files are easier to organize and reuse. The defer attribute lets the browser download a script while parsing HTML and run it after parsing.

Use the console for early feedback

Run a small expression and inspect output in developer tools. Check that the script path is correct and that the markup exists before querying it. Syntax, variables, and functions provide the foundation for page interaction.

Load a script

The defer attribute lets the browser parse the HTML before running an external script. Keeping code in a separate file makes it easier to organize and maintain.

<script src="app.js" defer></script>

Practice

Create an HTML page, load app.js with defer, and use console.log() to display a greeting.
