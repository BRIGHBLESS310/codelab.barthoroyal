Use color with purpose

Color utilities set text, background, border, and other color properties. Tailwind's palette provides named shades; projects can use a theme palette so product colors stay consistent.

Key idea

Choose colors for contrast and meaning, not decoration alone. Pair status colors with text or an icon, and check foreground/background contrast for the actual rendered pair.

Build a deliberate color system

Color utilities can set text, backgrounds, borders, and accents using Tailwind's palette. A numbered shade often represents a step in a scale, which makes it easier to choose related colors consistently than to invent a new value for every element.

Use color to reinforce information hierarchy and meaning, but do not make color the only way to distinguish success, warnings, or errors. Add text, icons, or other cues, and verify contrast between foreground text and its background—especially for small or low-weight text.

Consider the complete component rather than one swatch: links need to remain recognizable, disabled text must stay legible, and a surface needs enough separation from the page behind it. This foundation also makes dark-mode variants and theme tokens easier to apply consistently.

Example

The pale background and dark text form a status message with two levels of text. The words communicate success even if color cannot be perceived.

<div class="rounded-lg bg-emerald-50 p-4 text-emerald-950">
  <p class="font-semibold">Saved successfully</p>
  <p class="mt-1 text-sm">Your changes are up to date.</p>
</div>

Practice

Create success, warning, and error messages. Give each a distinct label or icon as well as color, and check the text remains readable.
