JavaScript Scope

Scope determines where a name is available. Variables declared with let and const are block-scoped; parameters and local variables are available within their function.

Understand the topic

Where a name can be accessed

Scope is the region where a declared name is visible. JavaScript has global, function, and block scopes; let and const are block-scoped, while parameters and local declarations belong to a function.

Closures preserve outer bindings

A nested function can use variables from where it was created even after the outer function returns. This closure behavior supports private state and callbacks. It captures bindings, not a frozen snapshot, so later updates can be observed.

Limit global state

A name may be unavailable outside its block, and using it before lexical initialization causes an error. Accidental globals create collisions and hidden dependencies. Keep variables near their use; closures and modules provide controlled sharing.

Use variables in scope

Keep variables close to where they are used. Closures let an inner function continue to access variables from its surrounding scope.

const course = "JavaScript";
function showCourse() {
    const message = "Learning " + course;
    return message;
}
console.log(showCourse());
