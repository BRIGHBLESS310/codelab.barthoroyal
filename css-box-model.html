The Box Model

Explore the box model through a practical example and a focused exercise.

How it works

Each element is a box made of content, padding, border, and margin. These layers affect its size and surrounding space.

Build the mental model

The box model measures an element's content area plus padding, border, and margin. Padding adds room inside the border; margin separates the element from its neighbors, and neither should be confused with the content size.

How to apply it

With the default content-box sizing, declared width describes only the content, so padding and borders increase the rendered total. box-sizing: border-box makes the declared width include content, padding, and border, which is often easier to reason about.

Common pitfalls

Margins can collapse vertically in some block-layout situations, so two adjacent margins do not always add together. Inspect the box-model diagram in browser tools when spacing seems surprising rather than compensating with arbitrary negative values.

*, *::before, *::after { box-sizing: border-box; }
.card { width: 20rem; padding: 1.25rem; border: 2px solid #cbd5e1; margin: 1rem; }

Calculate the total outer size from the declared width and the example's padding and border, then repeat the calculation with border-box sizing.

Practice

Give a card width, padding, border, and margin. Inspect its dimensions in developer tools.
