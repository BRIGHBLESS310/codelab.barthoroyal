Conditions and Loops

Explanation

Conditions select which code runs; loops repeat work over collections or until a condition changes. foreach is usually clearest for visiting array items. Validate values before relying on them.

Conditions select a branch based on a boolean expression; loops repeat code while a condition holds or for each item in a collection. Use strict comparisons to avoid surprising type coercion, and test boundary cases such as empty input or a value exactly at a threshold.

foreach is generally the clearest way to process array values. A while loop is appropriate when the number of repetitions depends on a changing condition, but ensure each pass can move toward termination to avoid an infinite loop.

Example

<?php
$score = 84;
if ($score >= 80) {
    echo "Pass";
} else {
    echo "Keep practicing";
}
