JavaScript Callbacks

A callback is a function passed to other code to be called later. Callbacks are common in event listeners and array methods.

Understand the topic

A function passed for later use

A callback is a function given to another function so it can be called at an appropriate time. The receiver might call it for each array item, after an event, or when work finishes. This lets reusable code delegate one specific behavior to its caller.

The receiving API determines timing and arguments

Check the API contract to learn when the callback runs and what arguments it receives. Array callbacks receive values and indexes; event listeners receive an event object. Pass a function value such as handleClick; writing handleClick() calls it immediately instead.

Keep asynchronous flow understandable

Deeply nested callbacks make the order of work and error handling difficult to follow. Name substantial callbacks and keep failures explicit. Promises standardize composition of asynchronous results, and async/await offers another readable style; both build on the callback pattern.

Pass a function

For multiple asynchronous steps, promises can make success and error paths easier to follow.

function greet(name, onDone) {
    console.log("Hello, " + name);
    onDone();
}
greet("Ada", () => console.log("Finished"));
