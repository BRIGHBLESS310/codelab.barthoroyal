Components and Props

Components split an interface into reusable units. Props are read-only inputs from a parent, useful for configuring child components without hard-coding repeated markup.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

A component is a reusable unit of interface. Modern React components are commonly JavaScript functions whose names begin with a capital letter; lower-case JSX tags name built-in HTML elements.

Props are inputs supplied by a parent, much like function arguments. They let a component vary its content without duplicating markup. Treat props as read-only; a child should notify its parent through a callback when an action changes data.

Destructuring props in the function parameter makes the values used by the component visible. Give each component a focused responsibility and stable name so repeated visual patterns can be changed consistently.

The parent passes Ada through the name prop, and Welcome renders it in a heading. Reusing the component with a different value changes its output without changing its markup.

Example

function Welcome({ name }) {
  return <h2>Welcome, {name}!</h2>;
}

function App() {
  return <Welcome name="Ada" />;
}
