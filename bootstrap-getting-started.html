Getting Started

Explore getting started through a practical example and a focused exercise.

How it works

Bootstrap provides CSS and optional JavaScript plugins. Include the stylesheet for the grid, utilities, and components.

Build the mental model

Bootstrap's CSS provides a baseline of styles, responsive layout classes, and reusable component conventions; its optional JavaScript bundle powers interactive plugins. Loading the CSS alone is enough for static styling, but components such as a collapse need the appropriate JavaScript.

How to apply it

The example pins a specific CDN release so markup and component behavior can be matched to the version's documentation. In a deployed project, verify the source and version and consider integrity and privacy requirements for third-party resources.

Common pitfalls

Bootstrap classes are conventions, not a substitute for understanding HTML or testing the result. Avoid mixing markup copied from different major releases, and do not load the JavaScript bundle when no JavaScript-driven component is needed.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js" defer></script>

Load the stylesheet and bundle separately in a test page, then identify which visible style works without JavaScript and which interaction depends on the bundle.

Practice

Create an HTML page, include Bootstrap 5.3, and add a container with a heading and button.

When ready, continue to Containers and Breakpoints. You can return to the Bootstrap course overview at any time.
