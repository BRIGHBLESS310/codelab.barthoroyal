Typography

Explore typography through a practical example and a focused exercise.

How it works

Typography choices affect readability and hierarchy. CSS can set font family, size, weight, line height, and spacing.

Build the mental model

Typography rules control font family, size, weight, line height, and spacing. A readable line height and a measure that is not too wide help readers keep their place, while a consistent type scale distinguishes headings from body copy.

How to apply it

Specify a fallback font stack because the preferred font may not be installed or may fail to load. Relative font sizing supports user preferences, and line height is often best kept unitless so it scales with the element's text size.

Common pitfalls

Decorative font choices and tightly packed lines can reduce readability; visual hierarchy should not depend on font size alone. Preserve sufficient contrast and avoid setting text so small that users must zoom to read it.

body { font-family: system-ui, sans-serif; line-height: 1.6; }
h1 { font-size: clamp(2rem, 5vw, 3.5rem); line-height: 1.1; }
p { max-width: 65ch; }

Compare the example's type choices at different zoom levels and verify that the hierarchy remains clear when the preferred font is unavailable.

Practice

Style an article with a clear heading scale and readable paragraph width. Test zoom and narrow screens.
