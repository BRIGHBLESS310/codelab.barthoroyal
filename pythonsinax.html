Python Syntax

Python syntax is the set of rules that gives code a valid structure. You can enter statements at the interactive prompt or save them in a .py source file; both are processed by a Python interpreter.

Execute Python Syntax

As we learned in the previous chapter, Python syntax can be executed by writing directly in the command line:

The interactive prompt reads and runs one statement at a time, which is convenient for quick experiments. A script file groups statements so you can save, edit, and rerun a complete program. In both cases, Python checks that the code follows its syntax rules before it can run.

Terminal Prompt 
C:\Users\Your Name>python
>>> print("Hello, World!")
Hello, World!

Python Indentation

Indentation refers to the spaces at the beginning of a code line. Unlike other programming languages (which use curly brackets `{}` for code blocks), Python uses indentation to indicate blocks of code.

A colon introduces a block after statements such as if, for, and def; the indented lines immediately below belong to that block. Use a consistent indentation width (four spaces is the common convention) so the code's structure is visible and predictable.

Indentation Example 
if 5 > 2:
    print("Five is greater than two!")

⚠️ Important: Python will give you an error if you skip indentation or use inconsistent spacing within the same code block!

A syntax error means Python could not parse the program, while an indentation error points specifically to block spacing. If a line runs in the wrong branch, compare its indentation with nearby statements before changing the condition itself. This connects directly to the decisions and loops covered later.
