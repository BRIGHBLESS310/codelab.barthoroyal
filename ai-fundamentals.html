Understand what AI means

AI describes a range of methods that enable computers to perform tasks commonly associated with human capabilities. Some systems use hand-written rules; others learn patterns from data; many products combine both.

Key idea

Start by describing the task and its success criteria rather than assuming that a product needs AI. A deterministic rule can be simpler, cheaper, and easier to verify when the task is well-defined.

AI is a capability, not a single technology

Artificial intelligence describes a broad family of computational approaches for tasks that appear to involve perception, language, reasoning, or decision-making. Some systems use explicit rules; others learn statistical patterns from data. The label “AI” alone does not explain how a system works or how dependable it is.

Machine learning is one area within AI: a model is fitted from examples rather than having every decision written as a rule. Generative AI is a further capability that creates content from learned patterns. These distinctions help you ask better questions about training data, evidence, uncertainty, and appropriate evaluation.

Assess a system by the task it performs, the people affected, and the consequences of errors. A narrow, automated recommendation may be useful without being able to reason like a person. Avoid attributing understanding or intention to a system when its actual behavior is pattern-based prediction or rule execution.

Example

The task names the input and desired result. Before selecting a model, define what counts as a correct route and how uncertain cases will be handled.

task = "route a message to a support team"
inputs = ["payment question", "login issue"]

# First define what a correct route means.
expected = ["billing", "account"]

Practice

Choose a familiar feature such as spam filtering. Describe its inputs, outputs, users, and an example of a wrong result that would matter.

Try the example, change one detail, and explain how the result changes.
