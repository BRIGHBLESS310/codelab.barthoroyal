Input and Expressions

std::cin reads formatted input. Arithmetic follows operator precedence; parentheses can make intent clearer. Check extraction when input may be invalid. std::getline reads a whole line, including spaces.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

std::cin reads formatted input. Arithmetic follows operator precedence; parentheses can make intent clearer. Check extraction when input may be invalid. std::getline reads a whole line, including spaces.

Formatted extraction with std::cin >> value reads a token and skips leading whitespace. Always check whether extraction succeeded before trusting the variable; invalid text can put the stream into a failure state. Use std::getline when a complete line, including spaces, is needed.

Arithmetic expressions follow precedence rules, but parentheses communicate intent and prevent mistakes when expressions grow. Mixing formatted input and getline requires care because a newline may remain in the input buffer. Validate input at the point it enters the program.

Example

#include <iostream>

int main() {
    int first{};
    int second{};
    if (std::cin >> first >> second) {
        std::cout << first + second << '\n';
    }
}
