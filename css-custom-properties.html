CSS Custom Properties

Explore css custom properties through a practical example and a focused exercise.

How it works

Custom properties store reusable values in the cascade, making design tokens easy to update consistently.

Build the mental model

A custom property begins with two hyphens and is read with var(). Because it participates in the cascade, a value declared on an element is available to that element and its descendants unless a nearer declaration overrides it.

How to apply it

Shared tokens for colors, spacing, or type scales make a design easier to update consistently. A fallback inside var() can supply a value when the referenced custom property is missing or invalid at the point of use.

Common pitfalls

Custom properties store token values, not complete selector rules, and their inheritance can make an override affect more descendants than expected. Name tokens by purpose and check the computed value when a declaration appears not to change.

:root { --color-brand: #0369a1; --space-card: 1.25rem; }
.card { border-color: var(--color-brand); padding: var(--space-card, 1rem); }

Change the token once and find every component that responds; then override it on one section to see how cascade inheritance scopes the change.

Practice

Create color and spacing tokens, use them in two components, and update a token once.
