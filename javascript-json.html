JavaScript JSON

JSON is a text format for exchanging data. Use JSON.stringify() to serialize compatible JavaScript values and JSON.parse() to read JSON text.

Understand the topic

A text format for exchanging data

JSON (JavaScript Object Notation) represents objects, arrays, strings, numbers, booleans, and null as text. It is common in network responses because many languages can parse it. JSON resembles JavaScript literals but follows stricter rules.

Parse text and serialize values

JSON.parse() turns valid JSON text into JavaScript values; JSON.stringify() converts supported values to JSON text. Keys and strings need double quotes, and JSON excludes comments, functions, and undefined. Some values are omitted or transformed during serialization.

Parsing success is not data validation

Malformed JSON makes JSON.parse() throw, so handle untrusted input. Valid JSON can still omit required fields or contain unexpected types; validate its structure before relying on it. JSON is a transport representation, often connecting fetch requests to objects and arrays.

Serialize and parse

Parsing can throw for invalid JSON. Validate data from outside your program before relying on its properties.

const data = { topic: "JavaScript", complete: true };
const text = JSON.stringify(data);
const copy = JSON.parse(text);
console.log(copy.topic);
