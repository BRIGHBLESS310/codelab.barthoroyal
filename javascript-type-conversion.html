JavaScript Type Conversion

Convert values explicitly when possible. This helps avoid surprises from implicit coercion, where JavaScript changes a value's type during an operation.

Understand the topic

Conversion changes a values type

Explicit conversion uses Number(), String(), or Boolean(); implicit coercion occurs when operators expect compatible operands. Deliberate conversion reduces surprises in arithmetic and conditional logic.

Inputs convert in different ways

Number("42") produces a number, while nonnumeric text gives NaN; an empty string becomes zero. Empty arrays and objects are truthy. Parsing functions may accept a numeric prefix, which is not the same as validating the entire input.

Validate the converted result

A conversion can succeed but still produce a value outside application rules. After converting form data, check whether it is finite and in range. Avoid relying on == coercion; explicit conversion makes comparisons easier to explain.

Convert deliberately

Check conversions that may fail: for example, Number("hello") produces NaN. Number.isNaN() can help detect an invalid numeric result.

const text = "42";
const amount = Number(text);
const label = String(amount);
console.log(amount + 1, label);

Practice

Convert a text input to a number and check whether the result is finite.
