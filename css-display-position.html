Display and Positioning

Explore display and positioning through a practical example and a focused exercise.

How it works

Display controls how an element participates in layout. Positioning places it in normal flow or relative to a containing block.

Build the mental model

The display property determines an element's layout behavior, such as block, inline, flex, or grid. It changes how the box participates in layout; it does not change the element's HTML meaning or its normal reading order.

How to apply it

Positioning values determine whether an element remains in normal flow, is offset relative to its usual place, or is positioned against a containing block or viewport. A positioned ancestor often establishes the reference for an absolutely positioned descendant.

Common pitfalls

Fixed and sticky elements can cover content, especially at high zoom or on small screens; leave room for them and test focus movement. Absolute positioning is not a substitute for a layout system when content should naturally reflow.

.card { position: relative; }
.card__badge { position: absolute; top: .75rem; right: .75rem; }

Toggle each display or position value one at a time and note which elements still reserve space in normal document flow.

Practice

Place a badge in a card corner. Check the card still works as its content changes.
