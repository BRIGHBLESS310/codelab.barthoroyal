Responsive Images and Tables

Explore responsive images and tables through a practical example and a focused exercise.

How it works

Bootstrap helpers let images scale within their parent and tables scroll horizontally on narrow screens.

Build the mental model

Responsive image classes let an image scale down to the width of its container while preserving its aspect ratio. This helps prevent overflow, but meaningful images still need suitable alternative text and sufficient intrinsic dimensions.

How to apply it

A responsive table wrapper allows a wide data table to scroll horizontally without forcing the entire page to overflow. Keep row and column headers meaningful so the relationships remain understandable while the user moves through the data.

Common pitfalls

Do not stretch a small image beyond its useful resolution or remove table semantics to fit a narrow screen. Horizontal scrolling should be limited to the table region and should not become the only way to reach other page content.
