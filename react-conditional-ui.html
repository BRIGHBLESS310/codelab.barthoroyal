Conditional UI

Render different elements based on a condition. JavaScript conditionals and logical expressions work in component code; choose the form that makes each UI state obvious.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

Conditional rendering chooses elements from a component's current data. An early return is clear when the whole view has a distinct state, such as loading; a ternary suits two short alternatives inside a layout.

JavaScript's && operator can render a fragment when true, but returns its left operand when false. With numbers, 0 && element displays 0, so use an explicit Boolean check when zero should render nothing.

Model loading, success, empty results, and errors as distinct outcomes. One truthy flag can hide those differences; named states or a status value make transitions easier to reason about.

The example returns a loading message until isReady is true, then returns the ready message. A data view should also distinguish an empty result from a failed request and provide accessible status feedback.

Example

function Status({ isReady }) {
  if (!isReady) return <p>Loading…</p>;
  return <p>Ready to go.</p>;
}

Practice

Show either an empty-state message or a list based on whether an array has items.
