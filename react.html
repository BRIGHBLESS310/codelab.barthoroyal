React Tutorial

React builds user interfaces from reusable components. Learn JSX, props, state, effects, and accessible composition while making the UI respond to data and user actions.

Learning goal: Create a component-based interface whose UI stays in sync with its data. Follow the course in order or choose a topic in the sidebar. Each lesson has its own page and previous/next links.

Start learning React

Begin with React Get Started. Read the explanation, try the example in a suitable environment, and complete its practice prompt.

  • Get Started: React components are JavaScript functions that describe interface output. Use a maintained project setup from the official React documentation; its build tools support JSX and module imports. JavaScript fundamentals make the course easier.
  • JSX and Rendering: JSX is a markup-like syntax transformed by the project toolchain. Put JavaScript expressions inside braces, use attributes such as className, and return a single parent or fragment.
  • Components and Props: Components split an interface into reusable units. Props are read-only inputs from a parent, useful for configuring child components without hard-coding repeated markup.
  • Conditional UI: Render different elements based on a condition. JavaScript conditionals and logical expressions work in component code; choose the form that makes each UI state obvious.

How to get the most from this course

  1. Work through the chapters in order; each topic links directly to its dedicated lesson file.
  2. Type and adapt examples instead of only reading them.
  3. Try the practice prompt, then use previous and next links to review or continue.
  4. Use a local development or practice environment for experiments.
