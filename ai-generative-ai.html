Understand generative systems

Generative AI produces content such as text, images, audio, or code based on learned patterns and a prompt. Fluent output is not proof that its claims are correct or grounded in reliable sources.

Key idea

Treat generated content as a draft. For factual or consequential tasks, verify claims against trusted evidence and make the system's limitations clear to users.

Generation is pattern-based, not lookup

A generative model learns statistical patterns from training data and produces a continuation or other output conditioned on an input. A language model, for example, repeatedly estimates likely next tokens. Its fluent answer is generated from learned patterns; it is not proof that the answer was retrieved from a reliable source.

Sampling settings influence how predictable or varied the output is, while the prompt and context shape what the model attempts to produce. A model can still produce plausible but incorrect details, especially when the question requires unavailable or current facts. Grounding and verification are separate system responsibilities.

Use generation where flexible synthesis is valuable, then constrain its role and evaluate real examples. For high-impact decisions, keep appropriate human judgment in the process. Model capability, data handling, output checks, and user expectations together determine whether a generative feature is suitable.

Example

The prompt supplies a task and source material. Reviewing every statement against that source helps catch unsupported additions.

prompt = "Summarize these meeting notes in three bullets."
result = generate(prompt, source_notes)

# Check that each bullet is supported by the notes.

Practice

Write a prompt to summarize a short public article. Create a checklist to verify that the summary preserves key facts and does not invent details.

Try the example, change one detail, and explain how the result changes.
