Spacing and Display Utilities

Explore spacing and display utilities through a practical example and a focused exercise.

How it works

Utility classes apply common spacing, display, alignment, and sizing styles without writing a custom rule for each case.

Build the mental model

Utility classes apply one narrowly scoped styling decision, such as spacing, display, alignment, or sizing, directly in markup. Bootstrap utilities can be responsive, allowing a property to change at a named minimum-width breakpoint.

How to apply it

Utilities are useful for small, local adjustments and quick layout composition. Repeated combinations can indicate that a reusable component class would communicate intent more clearly and reduce duplication.

Common pitfalls

A long chain of utilities can hide the structure and make responsive behavior difficult to reason about. Keep semantic HTML independent of presentation and avoid conflicting utilities whose outcome depends on generated CSS order.

Practice

Align a section heading and link with responsive utilities; keep their order logical on a phone.
