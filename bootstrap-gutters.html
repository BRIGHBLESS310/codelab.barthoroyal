Grid Gutters

Explore grid gutters through a practical example and a focused exercise.

How it works

Gutters are the spaces between grid columns and rows. Bootstrap spacing classes let you tune those gaps consistently.

Build the mental model

Gutters are the horizontal and vertical spaces between grid columns and rows. Bootstrap implements them with padding on columns and compensating row margins, which keeps content aligned with the surrounding container.

How to apply it

Gutter utility classes adjust spacing at all widths or from a selected breakpoint, and can affect both axes or just one. Consistent gutters make related cards easier to distinguish without adding arbitrary margins to every child.

Common pitfalls

Removing gutters entirely can make adjacent content hard to scan, while large gutters can squeeze columns at narrow widths. Be aware that custom row margins or nested containers can interrupt the expected alignment.

<div class="row g-3">
  <div class="col-12 col-sm-6 col-lg-4"><article class="p-3 border rounded">One</article></div>
  <div class="col-12 col-sm-6 col-lg-4"><article class="p-3 border rounded">Two</article></div>
</div>

Change the gutter size and inspect both the space between columns and the alignment of the row with the container edge.

Practice

Add horizontal and vertical gutters to a card grid and inspect it on mobile and desktop.
