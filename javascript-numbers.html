JavaScript Numbers

JavaScript uses the Number type for most numeric values. It includes special values such as NaN and Infinity. Decimal calculations use floating-point arithmetic.

Understand the topic

One type for ordinary numbers

JavaScript uses Number for integers and fractional values using floating-point representation. The same type includes NaN, Infinity, and negative infinity. Numeric literals can be decimal, binary, octal, or hexadecimal.

Precision and conversion affect results

Many decimal fractions cannot be represented exactly in binary floating point, leading to tiny rounding differences. Convert text deliberately and check results with Number.isFinite() or Number.isNaN(). For exact currency arithmetic, store integer minor units.

A numeric-looking string is still text

"12" is a string until converted, and operators can coerce it differently. Check whole-number requirements separately with Number.isInteger(). Numeric fundamentals support comparisons, Math operations, and reliable form handling.

Check numeric results

Use Number.isNaN() and Number.isFinite() to check numeric results. Applications involving money should account for floating-point precision.

const result = 0.1 + 0.2;
console.log(result);
console.log(Number.isFinite(result));

Calculate a percentage and check the result with Number.isFinite().
