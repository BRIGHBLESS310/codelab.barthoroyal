Get Started

A C++ source file is compiled into a program with a compiler such as GCC, Clang, or MSVC. Use a recent compiler and select a language standard such as C++17 or newer.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

A C++ source file is compiled into a program with a compiler such as GCC, Clang, or MSVC. Use a recent compiler and select a language standard such as C++17 or newer.

Compilation translates source code into a program the operating system can run. The compiler checks syntax and types, then reports diagnostics with file and line information; read the first error carefully because later errors may be consequences of it.

Keep source files separate from the generated executable, and rebuild after changing code. Compiler commands differ by platform; practice with a current compiler and an explicit standard such as C++17. Unlike browser JavaScript, C++ must be compiled before its program runs.

Example

#include <iostream>

int main() {
    std::cout << "Hello, CodeLab!\n";
    return 0;
}

Run or adapt this example in an appropriate local learning environment. Pay attention to the inputs, the result, and any assumptions the code makes.

Practice

Compile and run the program, change its output, and rebuild to verify the edit.

Before continuing, explain the example in your own words and try one variation.
