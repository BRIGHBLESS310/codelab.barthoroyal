Java Conditions and Switch

Conditional statements let a program choose what to do based on a boolean expression. The condition inside parentheses must evaluate to true or false.

If and else

Use if for a decision, else if for additional cases, and else for the remaining case.

int score = 82;
if (score >= 90) {
    System.out.println("Excellent");
} else if (score >= 70) {
    System.out.println("Pass");
} else {
    System.out.println("Try again");
}

Conditions are checked from top to bottom. Once a matching branch runs, the remaining branches are skipped.

Order branches from the most specific case to the broadest. In the example, checking for score >= 70 before score >= 90 would make the excellent branch unreachable because every excellent score would already match the pass condition.

Boundary tests expose mistakes: try values immediately below, at, and above each threshold. Use braces even for a one-statement branch while learning; they make each branch's boundaries visible and reduce errors when you add a second statement later.

Combine conditions

Use logical operators to express multiple requirements. Add parentheses when they make a compound condition easier to understand.

int age = 19;
boolean hasTicket = true;

if (age >= 18 && hasTicket) {
    System.out.println("Entry allowed");
}

Use parentheses to make complex combinations easier to parse, for example (age >= 18 && hasTicket) || isStaff. Because && has higher precedence than ||, explicit grouping can prevent a reader from misinterpreting the policy.

Conditions should express a clear yes-or-no question. Giving a meaningful boolean expression or variable a name can help make long decision rules easier to review and test.

Switch statements and expressions

A switch is useful when one value is compared against several fixed alternatives. Modern Java also supports switch expressions that return a value.

int day = 2;
String dayName = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Another day";
};
System.out.println(dayName);

Switch expression syntax requires a recent Java version. If your JDK is older, use a traditional switch statement with case labels and break.

A switch is a good fit when one expression is matched against a set of discrete alternatives, such as an enum value or command code. For ranges such as scores above and below thresholds, an if/else if chain communicates the intent more directly.

The arrow form avoids accidental fall-through: only the selected case is evaluated, and the switch expression must produce a value for every possible input, commonly using default. Traditional switch statements need explicit break statements when execution should not continue into the next case.

Practice

Write a program that assigns a letter grade based on a score. Test values just below and above each boundary to check your conditions.
