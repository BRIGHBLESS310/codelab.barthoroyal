More Python Topics

This lesson brings together collections, control flow, functions, and classes. These features build on variables, values, comparisons, and indentation to help you organize larger programs.

Tuples

Tuples are ordered sequences that cannot be changed after creation. They are useful for fixed groups of related values.

point = (4, 7)
x, y = point
print(x, y)

Like lists, tuples keep items in order and support indexing, slicing, and iteration. Unlike lists, a tuple cannot have its items added, removed, or replaced after it is created, which makes it useful for a fixed record such as coordinates or a function's multiple return values.

The example uses tuple unpacking: Python assigns each item to a matching name. The number of names must match the number of items, or unpacking raises an error. A one-item tuple needs a trailing comma, as in (4,), to distinguish it from a parenthesized number.

Sets

Sets hold unique values and support efficient membership checks and set operations.

languages = {"Python", "Java"}
languages.add("Rust")
print("Python" in languages)

Adding a value already present does not create a duplicate, which makes sets useful for deduplication and checking whether an item has been seen. Sets are unordered, so do not depend on the displayed order or try to retrieve a value by numeric index.

Set operations such as union, intersection, and difference compare groups of values. Elements must be hashable, so immutable values such as strings and numbers work as elements while mutable lists do not. Use a list instead when order or repeated entries matter.

Dictionaries

Dictionaries map keys to values. Use clear, hashable keys and handle keys that may be absent.

person = {"name": "Ada", "age": 36}
print(person.get("name"))
person["city"] = "Lagos"

A dictionary is useful when values have labels: a program can retrieve a person's name by its key instead of remembering a numeric position. Keys are unique; assigning to an existing key replaces its value, while assigning to a new key adds an entry.

Bracket lookup raises KeyError when a key is missing. Use get() when absence is expected or provide a default, and choose stable immutable keys such as strings. Dictionaries connect naturally to data types: their values can themselves be lists, other dictionaries, or any other Python objects.

If...else

Conditions choose which block runs. Python uses indentation to define each block.

score = 82
if score >= 70:
    print("Pass")
else:
    print("Try again")

The condition is evaluated as true or false. Python runs the indented block after if when it is true; otherwise, the optional else block runs. Use elif to test another condition in order, and remember that only the first matching branch is selected.

The colon begins each block and indentation marks its boundaries, linking conditionals to the syntax lesson. Keep related checks together and consider boundary values when testing comparisons—for instance, check scores just below, equal to, and above the passing threshold.

While loops

A while loop repeats while its condition is true. Ensure the loop can eventually stop.

count = 3
while count > 0:
    print(count)
    count -= 1

Python checks the condition before every iteration, so a false condition at the start means the body runs zero times. In this example, the counter is reduced on each pass until the condition becomes false; that change is what guarantees progress toward stopping.

If no part of the loop can make its condition false, the loop can run indefinitely. Use a while loop when repetition depends on a condition or user input, and keep the update that changes the condition easy to spot.

For loops

A for loop visits each item in an iterable, such as a list or a range.

for number in range(1, 4):
    print(number)

On each iteration, the loop variable receives the next item. range(1, 4) produces 1, 2, and 3: its start is included and its stop is excluded. This makes ranges work naturally with zero-based indexes and adjacent slices.

A for loop is usually the clearest choice when processing every item in a collection, while a while loop is useful when the stopping point depends on a changing condition. Avoid changing the collection being iterated unless you have planned for how its positions change.

Functions

Functions group reusable behavior. Parameters provide inputs, and return sends a result back.

def double(number):
    return number * 2

print(double(5))

def defines a function, and its indented body runs when the function is called. The value inside the parentheses is a parameter; the call supplies an argument. This separation lets one implementation work with many input values.

return passes a result back to the caller, where it can be stored or used in another expression. A function without a return statement returns None. Give functions focused names and responsibilities so they are easier to test and reuse.

Lambda expressions

A lambda is a small anonymous function expression. Use a regular def when behavior needs a name or multiple steps.

names = ["Mina", "Ada", "Zoe"]
print(sorted(names, key=lambda name: len(name)))

The lambda expression takes one argument, name, and returns its length. The key parameter tells sorted() which value to compare for each item, so the names are ordered by length rather than alphabetically.

A lambda can contain only a single expression and is best for short behavior passed directly to another function. If the operation needs explanation, multiple steps, or repeated use, a named function communicates intent more clearly.

Arrays

For general-purpose sequences, Python's built-in list is commonly used. The array module can store compact sequences of numeric values of a specified type.

from array import array
scores = array("i", [10, 20, 30])
print(scores[0])

The type code "i" requests an array of signed integers, so its values must match that element type. Arrays can use less memory than lists for large, uniform numeric sequences, but they are less flexible because they cannot mix arbitrary object types.

For most everyday collections, a list is the simpler choice. Specialized numerical workloads may use libraries such as NumPy, which provide additional operations; choose a representation based on the data and operations you need rather than using an array solely because it exists.

Classes and objects

A class defines a type; an object is an instance of that type. Keep classes focused on a clear responsibility.

class Greeter:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Hello, {self.name}"

print(Greeter("Ada").greet())

Calling Greeter("Ada") creates an instance and invokes __init__ to initialize its state. The parameter self refers to that particular object; self.name stores data that the object's other methods can use.

Methods are functions defined on a class, and calling one through an instance supplies that instance as self. Classes are useful when data and related behavior belong together, but a small script may be clearer with ordinary functions and collections. This connects object-oriented design to the variables and functions learned earlier.
