CSS Grid

Explore css grid through a practical example and a focused exercise.

How it works

Grid defines rows and columns for two-dimensional layouts. Tracks can be explicit or automatically fitted to available space.

Build the mental model

CSS Grid lays out items in rows and columns at the same time. Explicit tracks can use fixed, flexible, or content-aware sizing, and the fr unit divides available space after other track sizes are accounted for.

How to apply it

Grid is useful when placement depends on relationships in both dimensions, such as a page with a header, sidebar, and main region. Functions like minmax() allow a track to flex while respecting a minimum size.

Common pitfalls

A grid with too many fixed-width tracks can overflow, while careless explicit placement may create confusing reading order. Prefer source order that remains meaningful and test intrinsic content such as long headings and images.

.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr)); gap: 1rem; }

Change the track definitions one at a time and compare the two-dimensional result with the one-axis arrangement Flexbox would produce.

Practice

Create a responsive grid with four cards and observe how columns change with viewport width.
