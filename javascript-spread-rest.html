JavaScript Spread and Rest

Spread syntax expands iterable items or object properties. Rest syntax collects remaining values; both use three dots, and their meaning depends on where they appear.

Understand the topic

Expand values or collect the remainder

Spread expands iterable values into individual items or copies enumerable object properties. Rest collects remaining function arguments or destructured values into an array or object. Both use ..., but their positions distinguish expanding from collecting.

Calls, arrays, objects, and parameters

Spread can pass an array as arguments, combine arrays, or create a shallow object copy. Rest parameters gather extra arguments and must be last. In destructuring, rest collects positions or properties not already selected.

Copies are shallow and later properties win

Nested objects remain shared after spreading. In object literals, later properties overwrite earlier ones, so order matters, especially when combining external data. Understand mutation and precedence when using spread to compose values.

Expand or collect values

Object spread creates a shallow copy. Nested objects are still shared references unless copied separately.

const first = [1, 2];
const combined = [...first, 3];

function sum(...values) {
    return values.reduce((total, value) => total + value, 0);
}
