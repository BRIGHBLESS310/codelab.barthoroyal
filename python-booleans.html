Python Booleans

The Boolean type has two values, True and False. Comparisons and logical expressions produce Boolean results, which programs use to decide what to do next.

Compare values

temperature = 22
is_warm = temperature > 20
has_ticket = True

if is_warm and has_ticket:
    print("Ready to go")

Comparison operators include ==, !=, <, >, <=, and >=. Use and, or, and not to combine conditions.

Each comparison evaluates to a Boolean value, so it can be stored in a variable or used directly in an if statement. Compound conditions are evaluated with short-circuit behavior: and stops when its left side is false, and or stops when its left side is true. This can avoid unnecessary work, but conditions should still be written clearly.

Truth values

  • Boolean values: Capitalize them as True and False.
  • Equality: Compare values with ==; a single = assigns a value.
  • Truthiness: Empty strings, empty collections, zero, and None are false in conditions.
  • Identity: Use is None to test for None; use == for value equality.

Python also treats some non-Boolean values as true or false in a condition. Empty strings and collections, numeric zero, and None are false; most other values are true. This is called truthiness and can make checks concise, but test for a specific condition when truthiness could hide an important distinction.

Use == to ask whether two values are equal, and is to ask whether two names refer to the same object. The conventional value is None check uses identity because None is a singleton. These Boolean expressions are the foundation for the branches and loops in the next lessons.
