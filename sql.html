SQL Tutorial

SQL (Structured Query Language) lets you define, query, and update relational data. Follow this course from your first query through relationships, transactions, and query design.

Learning goal: Read and shape relational data, define integrity rules, and make data changes safely. Follow the course in order or choose a topic in the sidebar. Each lesson has its own page and previous/next links.

Start learning SQL

Begin with SQL Get Started. Read the explanation, try the example in a suitable environment, and complete its practice prompt.

  • Get Started: Relational databases organize information into tables of rows and columns. SQL is the language used to define tables and ask questions about their data. SQLite, PostgreSQL, and MySQL are common engines; some syntax differs among them.
  • SELECT and FROM: SELECT chooses the columns to return and FROM identifies the table. Name only columns you need: explicit selections are easier to read and avoid transferring unnecessary data. Aliases give result columns clearer names.
  • Filtering and Sorting: WHERE filters rows, ORDER BY sorts results, and LIMIT can cap the number returned. Use parentheses when mixing AND and OR. IS NULL checks missing values; comparisons with NULL do not behave like ordinary equality.
  • INSERT, UPDATE, DELETE: INSERT adds rows, UPDATE changes matching rows, and DELETE removes them. Before changing data, inspect the target with SELECT and ensure UPDATE or DELETE has a specific WHERE clause. Practice on a disposable copy.

How to get the most from this course

  1. Work through the chapters in order; each topic links directly to its dedicated lesson file.
  2. Type and adapt examples instead of only reading them.
  3. Try the practice prompt, then use previous and next links to review or continue.
  4. Use a local development or practice environment for experiments.
