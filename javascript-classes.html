JavaScript Classes

Classes provide syntax for creating objects with shared methods. Use a constructor to initialize instance properties and extends to define a subclass.

Understand the topic

A template for related objects

A class defines a pattern for creating objects that share methods and expected fields. Its constructor initializes each instance, and methods describe behavior the instances can use. Calling the class with new creates an instance.

Instances and inheritance

Class methods are shared through the prototype rather than copied as separate functions to every instance. A subclass can extend a base class and use super() to initialize inherited state before accessing this. Inheritance fits ?is a? relationships; composition is often simpler for combining capabilities.

Classes do not enforce correctness automatically

A constructor does not validate its inputs, and ordinary fields are not private by default. Keep constructors focused on establishing valid state and use private fields if encapsulation is needed. Plain objects may be clearer for simple records; classes help when instances have shared behavior.

Create a class

JavaScript classes use prototypes under the hood. Choose classes when they make object creation and behavior easier to organize.

class User {
    constructor(name) {
        this.name = name;
    }

    greet() {
        return "Hello, " + this.name;
    }
}
