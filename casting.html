Python Casting

Casting means explicitly converting a value to another type. Python's constructors such as int(), float(), and str() create converted values when the source can be interpreted in the requested way.

Convert between common types

age_text = "18"
age = int(age_text)
price = float("4.75")
message = str(age)

print(age + 2)
print(price)
print(message)

Conversion succeeds only when the input can be interpreted as the requested type. For example, int("hello") raises a ValueError.

A common reason to cast is that data from a form, file, or network often arrives as text. Convert it before doing arithmetic, and decide how to handle invalid input rather than assuming every string contains a valid number. Casting does not change the original value; it produces a new value with a different type.

Common conversions

  • To integer: int("42") converts a valid integer string; converting a float truncates its fractional part.
  • To float: float("3.5") converts a numeric string to a floating-point value.
  • To string: str(42) creates the text "42".
  • To boolean: bool(value) follows Python's truth-value rules; empty collections and zero are false.

Converting a float to an integer truncates toward zero: int(3.9) becomes 3 and int(-3.9) becomes -3; it does not round to the nearest integer. By contrast, converting a numeric string such as "3.9" directly with int() fails because that text is not an integer literal.

Use float() when fractional values are valid and str() when you need to combine a value with text. For user input, catch ValueError around conversions and give a helpful message; this connects type conversion to input validation and error handling.

Practice

Read a number as text, convert it safely, and handle invalid input with try/except ValueError. Validate user input before relying on its type.
