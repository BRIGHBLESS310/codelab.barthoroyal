Python Operators

Operators are symbols and keywords that perform work on values. They support arithmetic, comparisons, logic, membership checks, and updates to variables.

Operator examples

price = 12.50
quantity = 3
total = price * quantity
is_large_order = quantity >= 3

print(total)
print(is_large_order)

Here, multiplication calculates a total and the comparison produces a Boolean value. Operators connect the values and variables introduced earlier to practical calculations and the decision-making in the Boolean and conditional lessons.

Main operator groups

  • Arithmetic: +, -, *, /, //, %, and **.
  • Comparison: Compare values with ==, !=, <, and related operators.
  • Logical: Combine conditions with and, or, and not.
  • Assignment: Update a variable with operators such as += and *=.
  • Membership: Use in to check whether a value occurs in a collection.

Parentheses make complex expressions easier to read and help control evaluation order.

Arithmetic operators include true division (/), floor division (//), remainder (%), and exponentiation (**). Floor division rounds down to the next integer, which matters for negative numbers; for example, -7 // 3 is -3. Use parentheses when precedence is not obvious rather than relying on a reader to remember every rule.

Comparison operators create conditions, while and, or, and not combine them. Membership with in checks whether a value occurs in a string or collection. Assignment operators such as += update a variable, but they are not comparisons: = assigns, whereas == tests equality.
