State with useState

State stores information that changes over time. useState returns the current value and a setter; calling the setter schedules a render. Use a functional setter when the next value depends on the previous one.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

State is data that belongs to a component and changes over time. useState returns the current value for this render and a setter; calling the setter schedules another render rather than changing the current variable in place.

The setter accepts a replacement value or an updater function. Use the function form when the next value depends on the previous one; React can apply queued updates without relying on a stale render snapshot.

State should describe information that affects the UI, not a duplicate of values calculable from existing props or state. Keep related state together when it changes as one unit, and split independent state when it clarifies behavior.

The counter starts at zero and renders its current value in the button. The functional setter increments from the latest value; lift state to a shared parent when several components need the same source of truth.

Example

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(value => value + 1)}>
    Count: {count}
  </button>;
}

Practice

Build a counter with increment and reset actions; add a sensible minimum for a decrement action.
