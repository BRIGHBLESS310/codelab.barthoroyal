Learn from labeled examples

Supervised learning uses examples paired with target answers. Classification predicts categories; regression predicts numeric values. The model learns associations in training data and is evaluated on examples it did not train on.

Key idea

Labels are not automatically objective truth. They may reflect inconsistent annotation or historical decisions. Understand how labels were produced before treating a prediction as ground truth.

Labels turn examples into a learning signal

In supervised learning, each training example pairs input features with a target label or value. A classifier learns to choose among categories, while a regression model estimates a numeric quantity. The label is the outcome the training process tries to predict for previously unseen inputs.

Training data must include useful examples of the cases the model will encounter. A random split into training and test sets can estimate generalization, but related or duplicated records across the split can cause leakage and an overly optimistic score. Keep the final test set separate from choices made during development.

Predictions are not certainty, even when the model returns a score. Choose evaluation measures that reflect the cost of different errors, and decide how uncertain cases should be handled. Human review or a safe fallback can be important when a wrong classification has meaningful consequences.

The examples train a text classifier to predict a category. The sample prediction must still be checked against a representative evaluation set.
