Classes and Encapsulation

Explanation

A class groups related data and operations. Keep implementation details private and expose a small public interface that maintains the object's rules. Initialize members in a constructor when appropriate.

A class defines a type: its data members represent state and its member functions define operations. Keep representation details private and expose a small public interface. A constructor establishes the object's initial state, and member initializer lists are the preferred way to initialize members.

Encapsulation lets a class preserve its invariants—for example, rejecting an invalid balance instead of allowing callers to assign arbitrary values. Prefer standard-library types such as std::string and std::vector as members rather than owning raw memory without a clear need.

Example

class Counter {
public:
    void increment() { ++value_; }
    int value() const { return value_; }
private:
    int value_{0};
};
