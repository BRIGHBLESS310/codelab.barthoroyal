Pseudo-classes and States

Explore pseudo-classes and states through a practical example and a focused exercise.

How it works

Pseudo-classes target a state such as hover, keyboard focus, checked, or first child. Provide visible focus for keyboard users.

Build the mental model

A pseudo-class selects an element based on its state or relationship without adding a class in the HTML. Examples include pointer hover, keyboard focus, checked form state, and structural positions such as the first child.

How to apply it

Interactive states need to work for more than a mouse: keyboard users need a visible focus style, and touch interfaces may not offer hover. A selector such as :focus-visible can help show focus when keyboard navigation makes it especially important.

Common pitfalls

Do not remove the browser outline without providing a clear replacement, and do not make hover the only way to discover essential content. Structural pseudo-classes depend on actual document order, so inspect the HTML before assuming which item will match.

a:hover { text-decoration-thickness: .15em; }
a:focus-visible { outline: 3px solid #f59e0b; outline-offset: 3px; }
input:checked + label { font-weight: 700; }

Test every state with both a pointer and keyboard navigation, and confirm the focus indicator is easy to see against each surrounding background.

Practice

Add hover and focus styles to links. Navigate by keyboard and verify focus is easy to see.
