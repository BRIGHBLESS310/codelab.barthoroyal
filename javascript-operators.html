JavaScript Operators

Operators combine values or update variables. Arithmetic operators include +, -, *, and /; logical operators include &&, ||, and !.

Understand the topic

Operators transform and combine values

An operator performs an action on one or more operands. Arithmetic calculates, assignment updates bindings, comparisons produce booleans, and logical operators combine conditions. The operator chosen determines an expression meaning and result.

Precedence and coercion shape expressions

Operators follow precedence rules; multiplication occurs before addition unless parentheses say otherwise. Parentheses also communicate intent. JavaScript may convert operand types for +, so explicitly convert when combining text and numbers.

Keep expressions readable

Compound assignments combine an operation with reassignment; prefix and postfix ++ produce different expression results. Dense expressions can hide evaluation order and side effects. Clear expressions reduce mistakes and lead into comparisons and conditions.

Calculate with operators

Use parentheses to make complex expressions easier to read, even when operator precedence would make them unnecessary.

const subtotal = 20;
const taxRate = 0.1;
const total = subtotal + subtotal * taxRate;
console.log(total);
