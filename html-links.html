Links and Navigation

Explore links and navigation through a practical example and a focused exercise.

How it works

Anchors navigate to another resource with href. Link text should explain its destination even when read out of context.

Build the mental model

An anchor with an href points to a destination: a relative or absolute URL, a fragment identifier, or another supported resource. Relative paths resolve from the current document's location, so a link that works on one page may need a different path in a nested folder.

How to apply it

Link text is the accessible name people use to decide whether to follow a link. Describe the destination or action in context instead of relying on repeated phrases such as “click here”; fragment links also need a matching, unique destination id.

Common pitfalls

A link navigates to a resource, whereas a button performs an action on the current interface. Do not use a placeholder # as a finished destination, and use target="_blank" only when opening a new tab is intentional and made clear.

<nav aria-label="Main navigation">
  <a href="index.html">Home</a>
  <a href="contact.html">Contact</a>
</nav>
<a href="https://example.com">Visit Example</a>

Follow the example's URL from the current file, then verify both the destination and whether the link text makes sense when read out of context.

Practice

Create a three-link site navigation. Use descriptive text and relative links for pages in your site.
