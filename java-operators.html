Java Operators and Math

Operators calculate values, compare data, and combine conditions. Understanding their result types helps prevent common logic errors.

Arithmetic operators

Java supports addition, subtraction, multiplication, division, and remainder. When both operands are integers, division also produces an integer.

int sum = 7 + 3;
int difference = 7 - 3;
int product = 7 * 3;
int quotient = 7 / 3;   // 2
int remainder = 7 % 3;  // 1
double decimal = 7.0 / 3;

Use a decimal operand when you need a fractional result. Parentheses make the intended order of operations explicit.

Integer division discards the fractional portion toward zero: 7 / 3 is 2, and -7 / 3 is -2. The remainder operator gives what is left after integer division, which is useful for checks such as testing whether a number is even with number % 2 == 0.

Java applies operators using precedence rules, so multiplication happens before addition unless parentheses say otherwise. Parentheses are especially helpful when an expression mixes arithmetic or when the intended grouping is important to a reader.

Comparison and logical operators

Comparisons return a boolean. Use && for AND, || for OR, and ! for NOT.

int age = 20;
boolean isAdult = age >= 18;
boolean hasPermission = true;
boolean mayEnter = isAdult && hasPermission;

Java's && and || short-circuit: the second expression is evaluated only when needed to determine the result.

Comparisons such as <, >=, and != produce a boolean that can be stored, combined, or used directly in an if. For objects such as String, use equals() to compare text contents; == checks whether two references identify the same object.

Short-circuiting can safely guard an operation that is only valid under a condition. For example, denominator != 0 && numerator / denominator > 1 checks the nonzero case first; the division is skipped when the denominator is zero.

Assignment and increment

Compound assignments combine an operation with storing its result. Increment and decrement change an integer by one.

int score = 10;
score += 5;  // score is now 15
score--;     // score is now 14

Use these operators as separate, clear statements while learning; embedded increments can make a larger expression harder to follow.

Compound assignments such as score += 5 make an update concise, but the variable must already have a compatible value. Incrementing changes the variable itself; assigning the result to another name is a separate operation.

Post-increment (value++) and pre-increment (++value) both increase the variable by one, but produce their old and new values respectively when used inside a larger expression. A standalone increment avoids that subtle distinction.

Useful Math methods

The Math class provides common operations such as absolute value, minimum, maximum, and square root.

int larger = Math.max(8, 12);
double distance = Math.sqrt(81);
double roundedUp = Math.ceil(3.2);

Math methods return values rather than changing their arguments. The return type may be double even when the input appears whole, so check the method signature when assigning its result to a variable.

Floating-point arithmetic is approximate because many decimal fractions cannot be represented exactly in binary. That is usually fine for measurements and graphics, but exact financial calculations need a decimal representation and deliberate rounding rules.

Practice

Calculate the average of three quiz scores. Make sure the division produces a decimal value, then use a comparison to decide whether the average meets a target.
