PHP Tutorial

PHP is a server-side language used to create web pages and APIs. Learn language fundamentals, request handling, safe output, and database access in this practical course.

Learning goal: Build a server-rendered feature while validating input, escaping output, and using safe database operations. Follow the course in order or choose a topic in the sidebar. Each lesson has its own page and previous/next links.

Start learning PHP

Begin with PHP Get Started. Read the explanation, try the example in a suitable environment, and complete its practice prompt.

  • Get Started: PHP runs on a server and can produce HTML, JSON, or another response. A PHP runtime is required; a browser cannot execute PHP directly. The server processes the file and sends the generated response.
  • Syntax and Output: PHP statements commonly end with semicolons. echo writes to the response. Treat values that might contain user input as untrusted, and escape them for the output context.
  • Variables and Types: PHP variables begin with $. Common values include strings, integers, floats, booleans, arrays, and objects. PHP is dynamically typed, but explicit checks and strict comparisons (===) improve reliability.
  • Strings and Arrays: Strings can be concatenated or interpolated. Indexed arrays hold ordered values; associative arrays map keys to values. Use foreach to iterate and avoid assuming untrusted arrays contain particular keys.

How to get the most from this course

  1. Work through the chapters in order; each topic links directly to its dedicated lesson file.
  2. Type and adapt examples instead of only reading them.
  3. Try the practice prompt, then use previous and next links to review or continue.
  4. Use a local development or practice environment for experiments.
