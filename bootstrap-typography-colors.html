Typography and Colors

Explore typography and colors through a practical example and a focused exercise.

How it works

Bootstrap typography and text utilities provide common styles. Semantic headings must still reflect the document outline.

Build the mental model

Bootstrap typography utilities provide consistent display sizes, font weights, alignment, and text colors. They change presentation; retain real heading elements in a logical hierarchy so visual size does not determine the document outline.

How to apply it

Theme colors communicate common roles such as primary action or warning, but text still needs enough contrast against its background. Semantic HTML should express meaning first, with utility classes chosen to present it.

Common pitfalls

Color names do not guarantee accessible contrast in every context, and color alone must not signal success, error, or required state. Review the result with contrast checks and make the message clear in text or a non-color cue.

<h1 class="display-5">Explore the coast</h1>
<p class="lead">A weekend guide to quiet beaches.</p>
<p class="text-secondary">Updated this week</p>

Change a heading's visual size without changing its element and confirm the page's semantic outline still reflects the intended hierarchy.

Practice

Create a page heading, lead paragraph, and update label. Check hierarchy and color contrast.
