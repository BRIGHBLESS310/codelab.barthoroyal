The Grid System

Explore the grid system through a practical example and a focused exercise.

How it works

Bootstrap’s grid uses containers, rows, and columns built on flexbox. Column classes define their share of a row.

Build the mental model

Bootstrap's grid composes a container, a row, and columns; the row handles horizontal alignment and gutters while column classes set their responsive share. The familiar 12-column system lets a layout combine widths that add up to a row.

How to apply it

Classes can specify different spans at successive breakpoints, so a main region can fill a small screen and share space with a sidebar on a wider one. Grid columns are flex items, which allows them to adapt to available space.

Common pitfalls

Place columns as children of a row and rows inside a container to preserve the intended spacing. Column counts that exceed the row's available span wrap, so check the total widths at each breakpoint.

<div class="container"><div class="row">
  <main class="col-12 col-md-8">Main</main>
  <aside class="col-12 col-md-4">Sidebar</aside>
</div></div>

Add the example's column spans at each breakpoint and verify that the columns occupy a full row without exceeding the grid's total.
