JavaScript Debugging

Use browser developer tools to understand errors and inspect program state. The console reports errors, and the debugger lets you pause at breakpoints.

Understand the topic

Debugging is a repeatable investigation

Debugging finds why actual behavior differs from expected behavior. Reproduce the issue reliably and reduce it to a small case; writing down the expected and actual result turns a vague symptom into a testable question.

Use browser developer tools

The console shows errors and values. Breakpoints pause execution so you can inspect local variables, the call stack, and the branch taken; stepping shows state changes. Conditional breakpoints help when a problem only appears with a particular input.

Verify the cause and nearby behavior

Changing many things at once obscures which change mattered. Read the stack trace, inspect types and boundaries, and make one focused fix. Re-run the failing case plus a nearby normal case; this connects debugging with careful testing.

A practical debugging process

Read the error message, inspect values near the problem, reduce the code to a reproducible example, and test boundary cases.

const values = [2, 4, 6];
const total = values.reduce((sum, value) => sum + value, 0);
console.log({ values, total });

Practice

Set a breakpoint in a loop and inspect how a variable changes on each iteration.
