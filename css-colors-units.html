Colors and Units

Explore colors and units through a practical example and a focused exercise.

How it works

CSS supports several color notations and length units. Relative units help designs adapt and scale with user preferences.

Build the mental model

Colors can be expressed using names, hexadecimal values, RGB, or HSL notation; transparency can be represented with alpha where the syntax supports it. Choose values with enough contrast for text and interactive indicators against their actual backgrounds.

How to apply it

CSS lengths include absolute units such as pixels and relative units such as em, rem, percentages, and viewport units. Relative values can respond to user font settings or container size, which helps a design remain adaptable.

Common pitfalls

A pixel-based design can become cramped when text is enlarged, and viewport units alone can make text excessively small or large. Use units according to the relationship you want to express, and test color contrast rather than judging color by appearance alone.

:root { --ink: #172033; --accent: hsl(196 88% 35%); }
.card { color: var(--ink); max-width: 42rem; padding: 1.5rem; }

Change the base font size and resize the viewport to see which dimensions follow the user's settings and which stay tied to the viewport.

Practice

Choose a text/background palette and use rem-based spacing. Confirm small text is readable.
