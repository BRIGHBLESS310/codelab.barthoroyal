JavaScript Browser Storage

localStorage stores string values in the browser across sessions. Use JSON to store structured data, and handle malformed or unavailable stored values.

Understand the topic

Browser storage persists small values

localStorage and sessionStorage store string key-value pairs. Local storage usually remains between browser sessions; session storage belongs to a tab page session. Both APIs are synchronous and suited to small amounts of data.

Serialize structured data

Storage values are strings, so use JSON.stringify() and JSON.parse() for structured data. Handle absent keys and malformed text; saved data may become outdated after an application changes. Storage access can fail in restricted settings, so account for errors.

Stored data is not secret or inherently trusted

Browser-profile users can inspect or modify web storage, so never put passwords or sensitive credentials there. Validate restored values and save only what the interface needs. Sensitive or authoritative data belongs on a properly secured server.

Save a preference

Do not store passwords, access tokens, or other sensitive secrets in browser storage.

const preferences = { theme: "dark" };
localStorage.setItem("preferences", JSON.stringify(preferences));
const saved = localStorage.getItem("preferences");
if (saved) {
    const restored = JSON.parse(saved);
    console.log(restored.theme);
}

Practice

Save a display preference and read it again when the page loads.
