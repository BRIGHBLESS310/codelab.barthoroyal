Responsive Design

Explore responsive design through a practical example and a focused exercise.

How it works

Responsive design adapts to available space rather than assuming a device. Flexible layouts can reduce the need for many breakpoints.

Build the mental model

Responsive design responds to available space and user settings instead of targeting one named device. Flexible containers, fluid media, and readable line lengths handle many screen sizes before any breakpoint is needed.

How to apply it

A media query applies a rule only when its condition, such as a minimum viewport width, is met. Choose breakpoints where the content no longer fits comfortably, then add a small number of layout changes rather than a separate design for every device model.

Common pitfalls

A viewport meta tag in HTML is needed for expected CSS-pixel behavior on mobile browsers. Test intermediate widths, zoom, and text enlargement too; a page that looks good at two preset widths can still fail between them.

.page { width: min(100% - 2rem, 70rem); margin-inline: auto; }
@media (min-width: 48rem) { .layout { grid-template-columns: 2fr 1fr; } }

Narrow the browser gradually and identify the point where the content needs a layout change, rather than choosing a breakpoint based on a phone model.

Practice

Make a one-column mobile layout and a two-column wider layout. Test intermediate widths too.
