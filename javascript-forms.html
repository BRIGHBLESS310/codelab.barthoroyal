JavaScript Forms

Listen for a form's submit event to handle submitted values. Prevent the browser's default navigation only when your script is taking responsibility for handling the submission.

Understand the topic

Forms collect structured input

An HTML form groups controls that let a person provide information. JavaScript can listen for its submit event, read values, then update the page or send data. Native form semantics remain useful even when adding custom behavior.

Read values and handle submission

Use named controls or FormData to collect values. Handle the form?s submit event rather than only a button, since Enter can submit too. Call preventDefault() when your code deliberately replaces normal submission.

Keep accessibility and validation in view

Associate every control with a label and give its name a clear meaning. Make keyboard interaction and error feedback understandable. Forms connect event handling, DOM updates, and validation; data sent to a server still needs server-side checks.

Read submitted values

Keep native form semantics so users can submit with a keyboard and assistive technologies.

const form = document.querySelector("#signup");
form?.addEventListener("submit", event => {
    event.preventDefault();
    const formData = new FormData(form);
    console.log(formData.get("email"));
});
