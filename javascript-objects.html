JavaScript Objects

Objects group related data in named properties. Use dot notation for known property names and bracket notation for dynamic names.

Understand the topic

Named properties describe a thing

An object groups related data as properties with keys and values. Use dot notation for known property names and bracket notation for computed names. A method is a property whose value is a function; object literals provide a concise way to create records.

Objects are reference values

Assigning an object copies its reference, not a separate object, so changes through either variable can be observed through the other. Destructuring reads selected fields and spread syntax can create a shallow copy.

Nested objects remain shared in shallow copies

A spread copy duplicates only the outer object; nested references remain shared. Check whether a property exists before assuming a value and avoid trusting external data automatically. Objects underpin classes, JSON data, and options passed to functions.

Read and update properties

Use optional chaining (?.) when a property may be absent, and avoid assuming untrusted data has the shape you expect.

const learner = { name: "Ada", lessonsCompleted: 3 };
console.log(learner.name);
learner.lessonsCompleted += 1;
