Flexbox

Explore flexbox through a practical example and a focused exercise.

How it works

Flexbox arranges items along one main axis and distributes space. It suits navigation bars and aligned component groups.

Build the mental model

A flex container lays out its direct children as flex items along a main axis; the cross axis is perpendicular. flex-direction sets the main axis, while justify-content distributes free space on it and align-items aligns items across it.

How to apply it

The example's gap creates consistent space between items without adding margins to each child. flex-wrap lets items move onto another line when their combined size no longer fits, which is often safer than forcing a narrow toolbar to overflow.

Common pitfalls

Flexbox is a one-dimensional layout tool; it handles a row or column of related items, not a complete two-dimensional page grid. Avoid using space distribution to compensate for unclear item sizing, and check the result with long labels and narrow widths.

.toolbar { display: flex; align-items: center; justify-content: space-between; gap: 1rem; flex-wrap: wrap; }

Resize the toolbar until it wraps, then change the direction and observe how the main and cross axes—and the alignment properties—change.

Practice

Build a toolbar with a title and action links. Resize the page to ensure items wrap without overlap.
