Python Lists

A list stores an ordered, mutable sequence of values. Lists can contain different types, though keeping related items consistent usually makes a collection easier to understand and process.

Create and update a list

fruits = ["apple", "pear", "mango"]
fruits.append("orange")
first_fruit = fruits[0]

for fruit in fruits:
    print(fruit)

List indexes start at zero. Use append() to add an item and slices such as fruits[1:3] to get a portion.

Because lists preserve order, an index identifies an item's position: index 0 is the first item, and -1 is the last. A slice includes its starting index and excludes its ending index. An index outside the list's valid range raises IndexError, so check the list length when positions may vary.

Lists are mutable, meaning methods such as append() change the existing list. This is useful for collecting results, but assigning the same list to another variable does not create an independent copy; both names then refer to the same object.

Useful list operations

  • Length: Get the number of items with len(items).
  • Membership: Check for an item with value in items.
  • Remove: Use remove(value) or pop(index) when appropriate.
  • Comprehensions: Build a new list from an iterable with a concise expression.
  • Copying: Remember that assigning a list to another variable does not make an independent copy.

remove(value) deletes the first matching value and raises an error if it is absent; pop(index) removes and returns the item at an index (the last item by default). These different behaviors matter when handling optional values. Avoid changing a list's size while looping directly over it, because items can be skipped as positions shift.

A list comprehension creates a new list from an iterable, often with a transformation or filter. For small, clear transformations it is concise; if the expression becomes difficult to read, use a regular loop instead. Lists are a natural next step after operators because they let one variable hold a sequence for iteration.
