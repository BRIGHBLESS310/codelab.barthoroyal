Align items with flexbox

Flex utilities expose the CSS flex layout model. Use flex for arranging items along one primary axis, aligning them, and distributing available space.

Key idea

Choose row or column based on the content flow. Add gap for deliberate spacing rather than relying on child margins, and let important controls wrap when space is limited.

Choose axes before alignment utilities

Flexbox lays out children along one main axis and one cross axis. With flex-row, the main axis runs horizontally; with flex-col, it runs vertically. justify-* distributes items on the main axis, while items-* aligns them on the cross axis.

This axis relationship is more useful than memorizing class names. For example, switching a row to a column also changes what “justify” means visually. If items refuse to shrink or wrap as expected, inspect flex sizing, available container width, and whether flex-wrap is needed.

Flexbox is especially effective for one-dimensional patterns such as toolbars, navigation, and aligned card actions. For a page with simultaneous row-and-column placement, CSS Grid is usually easier to reason about. Selecting the layout model first prevents piling alignment utilities onto the wrong container.

Example

The outer flex container aligns brand and navigation, while the inner container spaces links. Wrapping lets the header adapt when the viewport narrows.

<header class="flex flex-wrap items-center justify-between gap-4">
  <a class="font-bold" href="/">CodeLab</a>
  <nav class="flex flex-wrap gap-3" aria-label="Main">
    <a href="/lessons">Lessons</a>
    <a href="/about">About</a>
  </nav>
</header>

Practice

Make a toolbar with a title on the left and two actions on the right. Add wrapping and a gap, then test at narrow widths.
