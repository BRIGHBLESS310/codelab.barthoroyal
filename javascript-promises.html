JavaScript Promises

A promise represents the eventual result of an asynchronous operation. Use then() for a successful result and catch() to handle a failure.

Understand the topic

A promise represents a future result

A promise represents an asynchronous operation that may fulfill with a value or reject with a reason. It starts pending and settles once. This lets code describe what to do when work completes without blocking the browser.

Compose work with then and catch

.then() registers a fulfillment handler and returns a new promise. A returned value becomes the next value; a thrown error rejects the chain. .catch() can handle a rejection and recover by returning a value.

Return asynchronous work to keep it connected

If a promise started inside a handler is not returned, the outer chain cannot wait for it and may miss its errors. Return dependent operations rather than nesting chains. Promise fundamentals explain async/await and parallel work with Promise.all().

Handle a promise

Returning a promise from a then() callback lets the next step wait for that operation.

Promise.resolve("Ready")
    .then(value => console.log(value))
    .catch(error => console.error(error));

Practice

Chain two then() calls and add a catch() handler for errors.
