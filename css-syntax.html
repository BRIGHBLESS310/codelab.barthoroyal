CSS Syntax and Rules

Explore css syntax and rules through a practical example and a focused exercise.

How it works

A CSS rule combines a selector with a declaration block. Each declaration pairs a property with a value.

Build the mental model

A CSS rule has a selector followed by a declaration block. Each declaration pairs a property with a value, and the semicolon separates declarations so the browser can parse the next one correctly.

How to apply it

The selector determines which elements may receive a rule; the property names the aspect to change, and the value supplies the setting. CSS is designed to tolerate many errors by ignoring an invalid declaration while applying other valid declarations in the same rule.

Common pitfalls

A missing brace can affect a large part of a stylesheet, while a misspelled property is usually ignored. Keep indentation consistent, use a browser's developer tools to inspect computed styles, and avoid repeating rules when one reusable selector can express the intent.

/* styles.css */
body {
  color: #172033;
  line-height: 1.6;
}
.card { padding: 1rem; border-radius: 0.75rem; }

Point to the selector, property, and value in the sample, then introduce one deliberate typo and use the browser inspector to see what is ignored.

Practice

Create rules for the page body and a reusable card class. Change a value and observe the result.
