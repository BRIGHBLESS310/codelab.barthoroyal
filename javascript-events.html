JavaScript Events

Events report actions or changes such as clicks, key presses, and page loading. Register a listener with addEventListener() to run code in response.

Understand the topic

Events report what happened

An event is the browser?s notification of an interaction or system change, such as a click, key press, submit, or load. Register a callback with addEventListener(); the browser invokes it when that event reaches the target.

Use event details and propagation

The callback receives an event object with information such as the target and event type. Events can bubble from descendants to ancestors, so a parent can handle many child interactions through delegation. This often simplifies dynamic lists.

Avoid accidental defaults and duplicate effects

Form submission and link clicks have browser defaults; call preventDefault() only when intentionally replacing them. Repeated listener registration can cause repeated actions. Event handlers connect DOM selection to interactive updates and should have a focused responsibility.

Listen for an event

Use event delegation for many similar child elements when it simplifies event handling.

const button = document.querySelector("#hello");
button?.addEventListener("click", () => {
    console.log("Button clicked");
});
