Strings and Arrays

Strings can be concatenated or interpolated. Indexed arrays hold ordered values; associative arrays map keys to values. Use foreach to iterate and avoid assuming untrusted arrays contain particular keys.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

Strings can be concatenated or interpolated. Indexed arrays hold ordered values; associative arrays map keys to values. Use foreach to iterate and avoid assuming untrusted arrays contain particular keys.

Indexed arrays store ordered items, while associative arrays use named keys. foreach is a readable way to visit each item. Use isset() or the null coalescing operator when a key may be absent, rather than assuming request data has a complete shape.

Strings can be joined with concatenation or interpolated inside double-quoted strings. Treat text from outside the application as untrusted: validate it for the intended purpose and escape it when rendering HTML. These habits connect collection handling to safe form processing.

Example

<?php
$student = ["name" => "Ada", "score" => 95];
foreach ($student as $key => $value) {
    echo htmlspecialchars((string) $key, ENT_QUOTES, "UTF-8") . ": ";
    echo htmlspecialchars((string) $value, ENT_QUOTES, "UTF-8") . "<br>";
}

Run or adapt this example in an appropriate local learning environment. Pay attention to the inputs, the result, and any assumptions the code makes.
