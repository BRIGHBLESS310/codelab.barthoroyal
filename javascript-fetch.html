JavaScript Fetch

The Fetch API makes HTTP requests and returns a promise. Check response.ok; HTTP error status codes do not automatically reject the fetch promise.

Understand the topic

Fetch makes an HTTP request

fetch() starts a network request and returns a promise that fulfills with a Response. Options specify details such as method, headers, and body. Read the response body separately, for example with response.json() for JSON.

Check status before using the body

Fetch usually rejects for network failures, but an HTTP status such as 404 still fulfills with a response. Check response.ok or response.status before treating it as success. Body parsing is asynchronous and can fail if the response is malformed.

Network results may be slow or unexpected

A request can fail, return no body, or return a different shape than expected. Handle loading, success, and error states, and validate data before use. Cross-origin access also depends on the server?s CORS policy. Fetch builds on promises and async/await.

Request and check data

Handle network failures and validate returned data before using it. Do not send sensitive information to untrusted endpoints.

async function loadData() {
    const response = await fetch("/data.json");
    if (!response.ok) {
        throw new Error("Request failed: " + response.status);
    }
    return response.json();
}
