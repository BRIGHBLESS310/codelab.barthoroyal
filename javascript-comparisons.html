JavaScript Comparisons

Comparison operators return a boolean. Prefer strict equality (===) and strict inequality (!==) so JavaScript does not first coerce different types.

Understand the topic

Comparisons produce a boolean

Comparison operators answer a question and return true or false. Equality, ordering, and identity checks can guide an if, be stored in a variable, combined with logical operators, or returned from a function.

Prefer explicit equality

Strict equality (===) compares without first converting operand types; loose equality (==) can apply surprising coercions. Relational operators compare two strings lexicographically, but compare numerically when both operands are numbers. Convert deliberately before comparing unlike types.

Check boundaries and unusual numbers

A condition score > 10 excludes 10; decide whether it should be inclusive. NaN is not equal to itself, so use Number.isNaN() to test it. Precise comparisons make conditions and validation more dependable.

Compare values

When comparing objects and arrays, equality checks whether they are the same reference, not whether their contents match.

console.log(5 === "5");
console.log(5 !== 4);
console.log(3 <= 3);
