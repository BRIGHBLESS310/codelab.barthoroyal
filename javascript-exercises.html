JavaScript Exercises

Practice by building small features and testing them in a browser. Break each project into steps and check the behavior after each change.

Understand the topic

Practice makes concepts usable

Exercises ask you to apply ideas to an input and expected output. Restate the task, identify the values involved, and write a small example first. A concrete example often reveals assumptions and edge cases before implementation.

Build a solution step by step

Start with the simplest case and implement one transformation or decision at a time. Use functions to isolate steps and test each with a few inputs. Once the main path works, try empty input, boundary values, and invalid values when relevant.

Check behavior, not just syntax

Valid syntax does not guarantee a correct answer. Explain why the output follows from your code, then change an input to see whether it remains sensible. Exercises using arrays, functions, and conditions build toward DOM-driven projects.

Project ideas

  • Create a temperature converter with input validation.
  • Build a task list that adds, completes, and removes items.
  • Make a quiz that tracks a score and displays a result.
  • Fetch JSON and show loading and error states.

For each exercise, consider empty input, repeated actions, and keyboard accessibility.

Try it yourself

Choose one exercise, sketch its interface, and implement one behavior at a time.
