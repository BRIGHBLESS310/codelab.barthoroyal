JavaScript DOM

The Document Object Model represents a web page as objects JavaScript can inspect and update. Select an element, then change its text or attributes in response to user actions.

Understand the topic

The DOM is a model of the page

The Document Object Model represents parsed HTML as a tree of nodes that JavaScript can inspect and change. Scripts can update text, attributes, classes, and structure without replacing the whole page. This is the foundation of interactive browser interfaces.

Change content safely

Use textContent for plain text and DOM methods such as createElement() and append() to build elements. innerHTML parses markup and is useful for trusted templates, but inserting untrusted strings can enable injection. Choose the narrowest update that meets the need.

DOM state can differ from source HTML

The DOM reflects parsed and modified page state, not just original source. Replacing a node can remove listeners attached to it. Selectors identify nodes, events report actions, and careful DOM updates turn user input into visible feedback.

Update page content

Prefer setting textContent for plain text. Avoid inserting untrusted strings as HTML.

const heading = document.querySelector("h1");
if (heading) {
    heading.textContent = "Welcome to JavaScript";
}

Practice

Select a heading in a test page and update its text after a button click.
