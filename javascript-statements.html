JavaScript Statements

A statement performs an action, such as declaring a variable, calling a function, or deciding which code to run. Expressions produce values and can be part of statements.

Understand the topic

Statements perform actions

A statement is an instruction such as declaring a variable, choosing a branch, or looping. Expressions produce values and can appear inside statements; an expression statement uses an expression for its effect. This distinction helps structure a program.

Blocks group related statements

Curly braces form blocks for functions, branches, and loops. Many statements end with semicolons, though JavaScript inserts them automatically in certain cases. Consistent style helps readability; automatic semicolon insertion can make some line breaks significant.

Make control flow explicit

A stray semicolon after an if condition can end the conditional early, leaving the following block unconditional. Braces make grouping clear. Statements provide the structure that variables, operators, conditions, and loops use to express an algorithm.

Run statements in order

A program runs statements in sequence unless control flow such as a condition, loop, or function call changes what runs next.

const price = 12;
const total = price * 2;
console.log(total);
