Python Data Types

A data type describes what kind of value an object represents and which operations make sense for it. Python determines the type of each value at runtime, and a variable name can later refer to a value of another type.

Getting the Data Type

You can get the data type of any object by using the type() function:

For example, the integer 5 and the text "5" look similar, but they support different operations: one can be added numerically, while the other is text. type() is useful when exploring values or diagnosing unexpected behavior; in larger programs, clear data flow is often better than repeatedly checking types.

Type Example 
x = 5
print(type(x))

Python Built-in Data Types

Python has the following data types built-in by default, in these categories:

Text values (str) hold characters, numeric types represent quantities, and sequence types keep values in an order. A list can be changed, while a tuple is fixed after creation; a range represents a sequence of integers without storing every item at once.

Text Type

str

x = "Hello World"

Numeric Types

int, float, complex

x = 20, 20.5, 1j

Sequence Types

list, tuple, range

x = ["apple", "banana"]

Mapping Type

dict

x = {"name" : "John", "age" : 36}

Boolean Type

bool

x = True

A dict maps unique keys to values for labeled lookup, while bool represents True or False and is commonly used in conditions. Choose a type based on how the data will be used: for example, use a list for an ordered collection that changes, or a dictionary when values need meaningful keys.
