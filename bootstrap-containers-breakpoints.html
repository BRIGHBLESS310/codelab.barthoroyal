Containers and Breakpoints

Explore containers and breakpoints through a practical example and a focused exercise.

How it works

Containers set responsive content widths. Bootstrap breakpoint classes apply at and above their minimum viewport width.

Build the mental model

A Bootstrap container provides horizontal padding and a responsive maximum width; a fluid container instead spans the available width. Both create a predictable boundary for page content and help align sections.

How to apply it

Bootstrap's breakpoint names represent minimum viewport widths, so a class such as col-md-6 applies at that breakpoint and above. This mobile-first rule lets a layout begin stacked and gain columns as space becomes available.

Common pitfalls

Breakpoints are not exact device categories, and choosing one should follow the content's fit. Do not combine container padding with ad hoc negative margins without understanding the grid's row alignment.
