Explanation

Compose interfaces from focused components and shared layout. Use semantic HTML, accessible names, and keyboard-friendly controls. A directory or task board makes a good first project.

Start with the example below, then change one value or condition and observe how the result changes. Check the documentation for your language or database version when details vary.

Example

function Card({ title, children }) {
  return <section className="card">
    <h2>{title}</h2>{children}
  </section>;
}

Run or adapt this example in an appropriate local learning environment. Pay attention to the inputs, the result, and any assumptions the code makes.

Practice

Build a searchable directory with empty/loading states, labeled controls, stable keys, and focused components.
