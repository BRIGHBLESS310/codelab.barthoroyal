JavaScript Loops

Loops repeat work. A for loop is useful when you need an index or known count; for...of iterates over values in an iterable such as an array.

Understand the topic

Repeat work over values or conditions

A loop repeats a block of statements. A for loop groups initialization, condition, and update; while repeats while a condition holds; for...of iterates values in an iterable such as an array.

Ensure the loop makes progress

The condition is checked repeatedly, so the body must eventually make it false or exit another way. Use break to stop and continue to skip an iteration when it improves clarity. Check index bounds carefully.

Match iteration to the task

A boundary like i <= items.length visits one invalid index. Avoid modifying a collection in a way that skips elements. Array methods can express transformations clearly, while loops fit custom control flow.

Iterate through values

Make sure loop conditions eventually become false. For arrays, use array methods when they make the operation clearer.

const colors = ["blue", "green", "gold"];
for (const color of colors) {
    console.log(color);
}
