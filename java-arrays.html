Java Arrays

An array stores a fixed number of values of one type. Arrays are useful when the number of items is known and you need to access them by position.

Create and access an array

Array indexes start at zero. An array with four items has valid indexes from 0 through 3.

String[] languages = {"Java", "Python", "C++"};
System.out.println(languages[0]);
System.out.println(languages.length);

Read the length property to find how many elements the array can hold. Accessing an invalid index causes an ArrayIndexOutOfBoundsException.

An array is an object with a fixed length chosen when it is created. Its elements all have the declared component type; primitive arrays hold primitive values, while arrays of reference types hold references to objects.

For a nonempty array, the final valid index is length - 1, not length. A loop that uses index < values.length avoids the common off-by-one error and also adapts when the array size changes.

Update and loop through values

Array elements can be changed, but the array's length is fixed after it is created.

int[] scores = {72, 85, 91};
scores[0] = 78;

for (int score : scores) {
    System.out.println(score);
}

Use an indexed loop when you need the position. Use an enhanced for loop when you only need each value.

Newly created array elements receive default values such as 0 for numeric primitives, false for boolean, and null for object references. Initializing each element intentionally prevents accidental reliance on these defaults.

An indexed loop is necessary to update an element, compare neighbors, or report its position. An enhanced loop emphasizes values instead. Choosing the loop form that matches the task makes array logic easier to read.

Calculate a total

A loop can accumulate a result. Initialize the total before looping, then add each value once.

double[] prices = {4.50, 2.25, 3.00};
double total = 0;
for (double price : prices) {
    total += price;
}
System.out.println("Total: " + total);

The total is called an accumulator: it begins with the identity value for addition, zero, and each iteration adds one element. Putting initialization before the loop matters, because resetting it in the loop would discard earlier work.

For an empty array, the loop body runs zero times and the total remains zero. Consider empty input and values at the limits of the chosen numeric type when writing general-purpose calculations.

When to use a collection instead

When you need a resizable sequence, use ArrayList. Arrays are still common for fixed-size data and are the foundation for understanding many other structures.

import java.util.ArrayList;

ArrayList<String> tasks = new ArrayList<>();
tasks.add("Practice arrays");

An ArrayList can grow as elements are added and provides methods such as add, get, and size. Unlike an array's length field, a list's size is queried with a method call.

Arrays are a natural choice when the number of elements is fixed or when an API requires an array. Choose a list when you need frequent insertion or removal; both structures still use zero-based positions for indexed access.
