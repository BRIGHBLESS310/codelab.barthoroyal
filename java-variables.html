Java Variables and Data Types

A variable is a named place to store a value. Java is statically typed, so each variable has a declared type that determines which values it can hold and which operations are available.

Declare and initialize variables

A declaration gives a variable a type and name. An assignment stores a value in it. Choose names that describe what the value represents.

String studentName = "Ada";
int completedLessons = 3;
double courseProgress = 0.75;
boolean isEnrolled = true;

Java distinguishes uppercase and lowercase letters. By convention, variable and method names use camelCase.

The declaration's type is part of the variable's contract: an int cannot later hold a String. A local variable must be assigned before it is read, while fields receive default values automatically; initialize values explicitly so their intended starting state is clear.

A variable name refers to a value, and assignment replaces the value stored under that name. Prefer descriptive names such as completedLessons over vague names such as x, especially when values have different units or meanings.

Primitive and reference types

Java has eight primitive types. Common ones include integers (int), decimal values (double), single characters (char), and true/false values (boolean). A String is an object reference type.

int count = 12;
long population = 8000000L;
double price = 19.95;
char grade = 'A';
boolean available = false;
String language = "Java";

Pick a type that fits the value. For money in real systems, consider decimal-safe types such as BigDecimal rather than binary floating-point.

Primitive variables hold simple values directly. A reference variable such as String holds a reference to an object, so it can also be null when it refers to no object. Calling an instance method through a null reference causes a NullPointerException.

Integer types have finite ranges, and arithmetic can overflow those ranges without automatically producing a larger type. Choose among int, long, and floating-point types based on the domain; literals that need to be long use an L suffix.

Constants with final

Add final when a variable should only be assigned once. This makes the value's intent clear and prevents accidental reassignment.

final int DAYS_IN_WEEK = 7;
final double TAX_RATE = 0.075;

A final local or field can be assigned only once. For a reference, final prevents reassignment of the reference; it does not necessarily make the referenced object's contents immutable.

Constants shared by a class are commonly declared static final and named in uppercase with underscores. A named constant communicates why a value is used and gives one place to update it safely.

Type conversion and casting

Some conversions, such as an int to a double, are widening conversions and happen automatically. A narrowing conversion needs an explicit cast because information may be lost.

int count = 7;
double exactCount = count;

double measurement = 9.8;
int wholePart = (int) measurement;
System.out.println(wholePart); // 9

Casting a decimal to an integer truncates the fractional part; it does not round to the nearest integer.

Widening conversions generally preserve the original value's magnitude, while narrowing conversions can discard fractional digits or high-order bits. The compiler asks for an explicit cast where data loss is possible, but the cast does not check whether that loss is acceptable to your application.

Mixed arithmetic follows Java's numeric promotion rules. For example, dividing two int values truncates before the result is assigned; converting the result afterward cannot restore the fraction. Convert an operand first or use a decimal literal when fractional arithmetic is intended.
