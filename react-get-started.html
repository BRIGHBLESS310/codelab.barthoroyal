Get Started

React components are JavaScript functions that describe interface output. Use a maintained project setup from the official React documentation; its build tools support JSX and module imports. JavaScript fundamentals make the course easier.

In this lesson: Read the explanation, follow the example, and try the practice prompt before continuing.

Explanation

React describes interfaces as a tree of components. A component is usually a JavaScript function that receives inputs and returns JSX; React renders that description into the DOM and updates parts that change.

A project needs tooling that understands JSX and JavaScript modules. Start with a maintained setup recommended by React's official documentation; this example uses createRoot from react-dom/client rather than the legacy rendering API.

The HTML page supplies the element with id root, createRoot connects React to it, and render mounts App. If the element is missing or the import path is wrong, the app cannot mount.

A development server rebuilds files and reports syntax errors. React does not require one router or data library, so add tools only when the application needs them and keep the first component small.

Example

import { createRoot } from "react-dom/client";
import App from "./App.jsx";

createRoot(document.getElementById("root")).render(<App />);
