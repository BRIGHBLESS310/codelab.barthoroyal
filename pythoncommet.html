Python Comments

A comment is a note for people reading a program; Python does not execute it as a statement. Comments can explain intent, clarify a non-obvious choice, or temporarily disable a line while you investigate behavior.

Creating a Comment

Comments in Python start with a hash symbol #, and Python will ignore everything from the hash mark to the end of the line:

A comment can appear on its own line or after executable code. Keep it accurate and focused on why the code exists, rather than restating an obvious operation; stale comments can be more confusing than no comment.

Single-line Comment Example 
# This is a comment
print("Hello, World!")

Comments can be placed at the end of a line, and Python will ignore the rest of the line:

Inline Comment Example 
print("Hello, World!") # This is also a comment

Multi-line Comments

Python does not actually have a built-in syntax for multi-line comments. To add a multi-line comment, you could insert a # for each line:

Putting a hash at the beginning of each line makes every line unambiguously a comment. Editors can usually add or remove these markers across a selected block, which is safer than relying on a string literal to hide code.

Multiple Hash Example 
# This is a comment
# written in
# more than just one line
print("Hello, World!")

Triple-quoted text is a string literal, not a special multi-line comment. An unassigned string expression may be discarded, but strings at the start of a module, class, or function can become documentation strings (docstrings). Prefer # for comments and use docstrings when documenting a module, class, or function.

Multiline String Comment 
"""
This is a comment
written in
more than just one line
"""
print("Hello, World!")
