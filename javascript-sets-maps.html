JavaScript Sets and Maps

A Set stores unique values. A Map stores key-value pairs and allows keys of any value type.

Understand the topic

Collections for unique values and key-value pairs

A Set stores unique values and helps remove duplicates or check membership. A Map stores key-value pairs and permits keys of any value type. Both preserve insertion order and offer methods for their collection roles.

Choose by how the data is used

Use add(), has(), and delete() for Set membership; use set(key, value), get(key), and has(key) for Map associations. A Map can be clearer than an object for non-string keys and frequent updates.

Object keys use identity

Two distinct objects with identical-looking properties are different Map keys. Set uniqueness follows value equality rules: repeated primitives collapse, but distinct object references remain. These collections complement arrays and plain objects when their constraints fit.

Store unique values and mappings

Choose a set for uniqueness and a map when keys should not be limited to object property strings or symbols.

const uniqueTags = new Set(["web", "code", "web"]);
console.log(uniqueTags.size);

const visits = new Map();
visits.set("home", 1);
console.log(visits.get("home"));

Practice

Use a Set to remove duplicate words, then a Map to store each word and its count.
