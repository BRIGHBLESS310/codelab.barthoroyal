Forms

Explore forms through a practical example and a focused exercise.

How it works

Bootstrap form classes style labels and controls but do not replace labels or validation logic. Keep instructions useful and visible.

Build the mental model

Bootstrap form classes standardize spacing and appearance for labels, inputs, help text, and validation feedback. They do not create the label-control relationship, enforce business rules, or submit the data on their own.

How to apply it

Connect every label's for value to the corresponding control's unique id. Use help text to explain format or purpose, and associate that description with the input when needed for assistive technology.

Common pitfalls

A placeholder disappears as the person types and is not an adequate replacement for a visible label. Validation styling must accompany understandable error text, and server-side validation is still required for submitted values.

<div class="mb-3">
  <label for="email" class="form-label">Email address</label>
  <input type="email" class="form-control" id="email" aria-describedby="emailHelp">
  <div id="emailHelp" class="form-text">We will only use this to reply.</div>
</div>

Click each label and test an invalid value; confirm the control's purpose and the correction needed remain clear without relying on its color.

Practice

Style a sign-up form with email and password inputs, labels, and concise help text.
