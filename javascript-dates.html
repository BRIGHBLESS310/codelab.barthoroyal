JavaScript Dates

The Date object represents a point in time. Date display depends on locale and time zone, so use explicit formatting for user-facing dates.

Understand the topic

A Date represents a moment

The Date object represents a point on the timeline as milliseconds relative to the Unix epoch. Create one with new Date() for the current time or supply a timestamp. Date objects can be compared using their numeric time value.

Time zones affect display

getFullYear() and getMonth() use local time; UTC variants use Coordinated Universal Time. Months are zero-based, a common off-by-one error. Use ISO representations for machine exchange and Intl.DateTimeFormat for locale-aware display.

Parse dates intentionally

Ambiguous date strings can be interpreted unexpectedly; invalid input yields an invalid Date whose numeric value is NaN. Decide whether a calendar date represents an instant and which time zone applies. Clear parsing and formatting choices prevent scheduling errors.

Format a date

For complex time-zone and calendar requirements, select a date-time solution that fits the application's needs.

const now = new Date();
const formatted = new Intl.DateTimeFormat("en", {
    dateStyle: "long"
}).format(now);
console.log(formatted);
