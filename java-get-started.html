Java Get Started

To write Java programs, install a Java Development Kit (JDK). It includes the Java runtime and tools such as javac, the Java compiler.

Check your installation

Open a terminal or command prompt and check that Java and the compiler are available:

java --version
javac --version

If a command is not recognized, install a current JDK and make sure its tools are available on your system's PATH. Follow the setup instructions for your operating system.

The JDK is the development kit: it contains the compiler and other tools needed to build programs. The Java runtime environment supplies the JVM and standard libraries needed to run compiled code; current JDK installations include what you need to run programs too.

Check that java and javac report compatible versions. If you have more than one JDK installed, your PATH may point to a different one than your editor uses, so verify the commands from the same terminal where you will compile.

Create a Java source file

Make a text file named Main.java. In this simple example, the public class is also named Main; Java expects those names to match.

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

The main method is where this application begins. For now, write it exactly as shown, then learn its parts in Java Syntax & Output.

Use a plain-text editor or an IDE and make sure the file is actually saved with the .java extension; some editors append .txt without making that obvious. Java identifiers are case-sensitive, so the spelling and capitalization of Main must remain consistent.

Compile and run

From the folder containing Main.java, compile the source file. If compilation succeeds, the Java compiler creates a class file containing bytecode.

javac Main.java
java Main

The expected output is Hello, World!. Run the class by its name without the .class extension.

Compilation translates source text into bytecode; it does not normally launch the program. The second command invokes the launcher, which looks for the compiled class on the class path and starts the JVM. If compilation reports an error, fix the source first because no usable class file may have been produced.

Run both commands from the directory containing the source and generated class for this first example. Later, Java projects commonly use packages and build tools to organize output folders, but the compile-then-run cycle is the same idea.

Common first errors

  • Filename mismatch: A public class called Main belongs in Main.java.
  • Missing semicolon: Most Java statements end with ;.
  • Case matters: Main, main, and MAIN are different names.
  • Wrong folder: Run the commands from the directory containing the source file.
  • Compiler versus runtime: Fix compilation errors before trying to run the class.

Practice

Change the program to print your name on a second line. Compile it again and run it. Then continue to Java Syntax & Output.
